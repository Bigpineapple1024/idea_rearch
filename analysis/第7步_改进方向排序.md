# 第 ⑦ 步：改进方向排序

状态：视觉方向已排序，**待用户选择**（2026-10-24）；时序方向在 EXP-0009 与 EXP-0004 阶段 B 完成后补入本文。排序只给建议，选择由用户做出，选定后记入 [version-evolution](version-evolution.md) 并进入第 ⑧ 步。

## 排序依据

按[研究流程](研究流程.md)第 ⑦ 步：

- 两个因素：解决后提升大不大，问题好不好解决。
- 普遍性：至少在第二个数据集或设置上确认问题仍在。
- 排序依据（从高到低）：
  1. 问题真实存在，并在本项目的 baseline 上造成可测的损失；
  2. 相近设置中同方向的修正被证明有效；
  3. 机制能给出单一方向的预测；
  4. 预期效应大于噪声；
  5. 成本只在前四项相当时决定先后。

这里的“成功”指：在本项目的 baseline（FastV，K=2，层平均 64）加上已知修正之后，在 POPE、MME 上取得超出配对区间的提升。新颖性单独列出，都只到检索摘要级。

排序理由：

- **候选 1 排第一。** 四条依据都满足：损失是本项目测到的，同一设置下已有方法证明可行，方向单一，效应大。风险在新颖性：要做出与 SparseVLM 不同的东西，可以把“题目相关的打分”放进已证明有效的覆盖框架（块内排序），或只在题目点名物体时启用。
- **候选 2 排第二。** 现象新、跨两个 benchmark，第 ⑥ 步也显示没有论文处理过这个位置。但修正能否成功取决于一个尚未测的机制：偏向是否是可平移的对数几率。按流程，“证据不足以判断时先做能估计成功可能性的诊断”。
- **候选 3、4 的依据 ① 或 ④ 还缺数据。** 新颖性也低。
- **候选 5 已被 EXP-0007 否定。**
