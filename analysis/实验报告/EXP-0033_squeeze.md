## 4. 解释与不确定性

- **最支持的解释**（AI，未检验）：在 64 档，DivPrune-64 的底座已经把“图上有什么”覆盖得较好；它剩下的缺口主要是“某个物体的属性、两者之间的比较”这类要看局部细节的题（F77）。K = 1 让第 0 层的题目 token 看过全部 576 个 patch，这类细节在第 0 层就进了题目的表示，所以 GQA 的属性、二选一题补回约一半（F78）；VQAv2 上同样的 K = 1 只留 47 个，计数、颜色题因 token 少而吃亏。
- **对 F75（DivPrune 的优势来自铺开）的影响**：X2 少铺开约 2.6 个块、准确率不变，也没有剂量关系（S2），“铺开”不足以解释 DivPrune 的增益（与“去掉特征空间的冗余”这一替代解释同样相容）。
- **仍可成立的替代解释**：开发集上的偶然（P14）；GQA 的属性、二选一题多是“问图中某个物体”的组合式长句，K = 1 的好处也可能来自位置编号保持原样（F6）而不是第 0 层全看；X3 的查询名额（平均 36 个）可能太多，换成按查询加权的多样性未必有害。
- **当前证据不支持的强结论**：“题目查询在多样性底座上有害”（区间含 0）；“DivPrune 的增益来自去冗余”（没有直接对照）；“按题型挑方法能提升”（交叉估计接近 0）。
