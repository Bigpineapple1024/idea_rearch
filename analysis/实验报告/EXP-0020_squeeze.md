## 4. 解释与不确定性

- **最支持的解释（AI，M16 的确认）**：答案就是被点名物体本身（在不在、有几个）的题，按题目词选 token 等于直接取证据；答案是物体的属性、动作或旁边东西的题，换掉第 2 层注意力最高的 token 有害。按句式路由在题目文字上近似区分这两类（test2 上 yes/no 类 99.5% 被路由；助动词开头的题 93.3% 是 yes/no 类，即 2010 / 2155，test1 为 92.7%），所以拿到前者的增益、避开后者的损失。
- **与 VisionZip 的差距（AI）**：差距在路由交给 A 的开放式题，是底座的差距，不是路由的。VisionZip 在视觉编码器里按 CLS 注意力选 token、再把其余 token 合并成少量 contextual token，保留了开放式题需要的整体内容；FastV 一族在 LLM 第 2 层按注意力选，丢掉了这部分（F40）。拼接组合与 VisionZip 无可检出差别，说明在被路由的题上，A′+B+V 与 VisionZip 相当（POPE 上更好）。
- **替代解释**：
  - ①yes/no 上的增益部分来自 yes 比例的改变，不全是区分力（S6）；POPE 上已测得区分力也提高（F41）。
  - ②128 档的增益大小随子集变化（S8），可能部分是抽样。
- **不支持的强结论**：本方法在一般题目上优于 VisionZip；更细的句式规则（S3）；拼接组合是一种已验证的方法。
