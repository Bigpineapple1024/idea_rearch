### 选择规则（写定）

- **候选**（同时也是相差不到 0.1 时的取用顺序，简单的在前）：`k1cls`、`k1qcls`、`k1qcls_c16`。
- **主指标**：Δ = 候选 − VisionZip-64，全部题准确率的配对差，两个开发集分别计，取平均 Δ̄。
- **选法**：选 Δ̄ 最大的候选；与最大值相差不到 0.1 的，按上面的顺序取第一个。

### 判读（写定）

- **有希望（进入确认）**：所选 − VisionZip-64 在两个开发集上都 > 0，且所选 − 每题覆盖 16（IDEA-0006 的所选，EXP-0028-R19、R20）的两集平均 > 0。

- **中间情况**：其余情形，交用户决定。
- **证据强度**（只报告）：所选 − VisionZip-64 的区间在 0 以上的开发集个数。
- **提升大**（只报告，不改判读）：所选的 Δ̄ ≥ +2.0。

### 归因（写定的读法，不改选择与判读）

- **一层全看**：`k1cls` − VisionZip-64，两集平均 > 0 → “一层全看 + CLS 排序（47 个）好于 VisionZip-64（64 个，含合并的 token）”。
- **排序**：`k1qcls` − K = 1 路由，只在不路由的题上，两集平均 > 0 → “K = 1 时 CLS 排序好于 FastV 的注意力排序”。
- **路由**：`k1qcls` − `k1cls`，只在被路由的题上，两集平均 > 0 → “被路由的题上题目查询路径好于 CLS 排序”。
- **覆盖**：`k1qcls_c16` − `k1qcls`，两集平均 > 0 → “一层全看之后覆盖仍有增益”。
