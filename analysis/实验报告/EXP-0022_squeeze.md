## 4. 解释与不确定性

- **二选一题为什么受益（AI，未测）**：二选一题把候选答案写进题目（“红色还是蓝色”“左边还是右边”），查询同时含话题物体与候选答案的词，选中的 token 直接是判断所需的证据。关系二选一题（+9.00）需要两个物体都在保留集合里，题目恰好点名了两者。
- **GQA 与 VQAv2 为什么不同（AI）**：
  - GQA 的开放式题由场景图生成，多问被点名物体本身的属性（颜色、材质、位置），查询选中的正是证据；答案是另一个物体的关系题仍受损，与 F44、F45 一致。
  - VQAv2 的开放式题更多需要整体内容（读字、what is this、场景），这正是 VisionZip 的合并 token 占优的地方（F43、M17）。GQA 上 A 与 VisionZip 的差距小，与此一致。
- **替代解释**：
  - ①GQA 的图更小（长边约 500 像素）、问句更规范，各种选择方法之间的差别整体更小；
  - ②yes/no 的增益与答案偏向分不开（S3），但路由后的 yes 比例与 vanilla、标准答案一致，不是过度答 yes；
  - ③语义类型的分组是事后的，属性类的 +2.36 只是一个子集上的探索结果。
- **不支持的强结论**：本方法优于 VisionZip；A′+B+V 在开放式题上普遍有害或普遍有益；按语义类型改路由规则（GQA testdev 已用于检验，不能再用来选规则）。
