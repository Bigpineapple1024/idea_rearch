## 4. 解释与不确定性

- **最支持的解释**（AI，未检验）：①**位置**：LLaVA 从图像 token 的位置编号（每行 24 个）读出空间布局；先剪后送、连续编号的方法（VisionZip、DivPrune、CDPruner、MMTok 的官方实现）丢掉了行与列，“在左边还是右边”这类题大幅下降（positionChoose 低 26 分）；保留原始编号几乎补回（F89）。②**偏“是”**：原始编号下只剩 61 个稀疏的 token，题目在第 0 层看不到其余部分，对“图里有没有”缺少反面证据，模型更常答“是”（LLaVA 在不确定时偏“是”）；连续编号的 64 个看起来像一张完整的小图，不偏；第 0 层让题目读到全部 patch 后，题目有了反面证据，“否”题的对数几率下降约 0.8～1.0，“是”题几乎不变（F88）。③增益与被点名的物体留下多少无关（F90），所以“借看”不是在找回漏看的物体，而是让是非判断有了全图的依据。
- **替代解释**：S1 的分组按标准答案，标准答案的分布在两个集不同；“否”题上的增益有一部分可能来自 GQA 某些细分题型的答案几乎都是“否”；VQAv2 的物体匹配只用题目文字；原始编号与少 3 个 token 混在一起（F87）；开发集上的偶然（P14）。
- **当前证据不支持的强结论**：“借看帮模型找到漏看的物体”（S3 没有剂量关系）；“原始编号在所有题上都更好”（是非题与计数题上更差）；位置题的结论只来自开发集的 GQA（在 EXP-0035 计划 v1.1 的二级分析里预注册检验）。
