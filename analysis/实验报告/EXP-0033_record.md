## 计划 v1（运行前写定）

### 问题（探索性：没有判据，预先写定要报告什么、什么算“意外”）

对每个组合 X = A + B，在同一层平均预算（64）下：

1. A+B 与 A、与 B 各差多少，在哪些题型上；
2. 是否出现“意外”（定义见“读法”）：比两者都好（互补），比两者都差（互相抵消），或在某类题上与整体方向相反；
3. A+B 留下的 token 与 A、B 各自留下的重合多少（能记录的组合）。

### 读法（预先写定，探索性，不是判据）

- 每个组合报告：A+B − A、A+B − B、B − A 的配对差，按图像重抽 1000 次（种子 0）；按题分组：VQAv2 的答案类型与颜色题，GQA 的结构类型与语义类型，被路由与不路由的题。
- **“意外”的三类**（任一集上满足即记录，并写明在哪个集、哪类题）：
  - **互补**：A+B − A 与 A+B − B 都 > 0，至少一个区间在 0 以上；
  - **互相抵消**：两者都 < 0，至少一个区间在 0 以下；
  - **题型反转**：某一题型（至少 300 题）上 A+B − max(A, B) 的区间不含 0，而且方向与整体相反。
- 其余结果（落在 A 与 B 之间、区间含 0）写成“没有意外”，同样登记。
- **同时报告**：各配置与不剪枝的差；X1、X2 中 A+B 留下的 token 与 A、B 各自留下的重合（Jaccard，能从记录得到的）；每题秒数与峰值显存；逐题翻转（得分不同的题、变好与变差各多少）。
- **预测（推断，写在这里只为事后对照）**：X1 接近 VisionZip-64（±1）；X2 落在 A 与 B 之间；X3 在被路由的 yes/no 题上略高于 DivPrune-64、整体变化小；X4 与 DivPrune-64 的差在 ±1 以内。任何一条预测落空都按上面的定义记为意外。
- **之后**：结果写进记录与 squeeze（SQZ-EXP-0033），新现象登记为 F（标“探索性组合”），回流 MODE_C-0002；出现意外的组合走第 ⑤ 步的 1a–2b。任何要写成方法的发现，都要先经过 Mode C 与 discover-innovation，并在新抽的数据上预注册确认（P14）。

### 实现核对（不满足就停止排查，门槛 ≥ 99%）

- 每个运行：每题一个答案；重算的准确率与计分文件、登记的准确率一致。
- X1：每次 prefill 第 0、1 层看到 128 个视觉 token，第 2 层起 60 个（逐层计数）；128 个等于 VisionZip-128 的输出（同一张图逐个相同）。
- X2：候选是 CLS 注意力的前 128 个；选出的 64 个都在候选里，且等于在候选上离线重算的最大最小顺序的前 64 个。
- X3：路由决定等于题目文字上的规则；被路由的题按查询取的个数等于 round(64 × S)（S 用离线的 IDF 与可视性表重算）；不路由的题选出的 64 个与 DivPrune-64 相同。
- X4：54 个等于 DivPrune 最大最小顺序的前 54 个；10 个上下文 token 等于离线重算的合并结果（数值容差）；进 LLM 的共 64 个。
