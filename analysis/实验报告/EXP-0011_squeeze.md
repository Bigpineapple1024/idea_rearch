## 4. 解释与不确定性

- **最支持的解释**（AI，有 D2、D2b、D3 支持）：
  - LLaVA 的投影把图像 token 放到与词 embedding 可比的空间。物体名的词 embedding 与对应区域的图像 token 相近，所以第 0 层之前就能按题目定位。
  - 前两层的注意力权重主要由图像 token 一侧的显著性与位置决定，体现不出这种对应。FastV 在第 2 层按注意力剪枝，所以与题目无关。
  - 换成输入层的余弦后，小物体被保住，召回接近 vanilla（78.0% vs 79.1%）。
- **副作用的解释**（AI，待复验）：题目问的是不存在的物体时，选择会留下“最像它”的区域，模型更容易被诱导答 yes。
- **仍可成立的替代解释**：
  - 收益部分来自 POPE 的题型（题目总是点名一个 COCO 类别）；
  - 误报的增加也可能来自“保留的 token 更集中在相似区域、覆盖变差”，而不只是“像”。
- **不支持的强结论**：
  - 方法在一般 VQA 上有效：没有测，而且需要先找出被问的物体；
  - “新方法”：同类的文本-视觉相似度选择已有 TRIM、ReDiPrune、CDPruner 等（检索摘要级）；
  - “减少幻觉”：误报反而增加。

## 6. 下一步决策

1. **最优先的检查**（第 ⑧ 步第 3 轮或第 ⑨ 步，需要用户定先后）：
   - **误报（F30）**：在开发集上检查两种不改变预算的修正：一部分名额按题目、一部分按覆盖；或用题型无关的 yes/no 校准（与候选 2 相连）。
   - **一般题目**：从任意题目中找出被问的物体或关键词（例如去掉模板词、按词频加权），先在开发集上确认不伤 POPE，再在 MME 上做无害检查。
   - **其他数据集**：GQA、TextVQA 需要下载图像（需要用户许可）。
2. **若结果保持**：进入第 ⑨ 步，用底层问题检索领域 B。底层问题是“查询目标可能不存在时，按查询相似度选子集会制造假证据”，可检索开放集识别、带拒识的检索、对比式打分。
3. **若一般题目上不成立**：方法限定为“点名物体的存在性问题”，论文中作为分析性结果。
