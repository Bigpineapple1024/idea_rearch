### 离线统计

R02、R03 各算一遍，口径相同。

- **三种打分**：
  - 最后一个 token 那一行（FastV 原样）；
  - 题目句（“Is there a X in the image?”）各 token 行的均值；
  - 物体名各 token 行的均值。
- **P1（与题目的关系）**：同一张图、不同题目时，top-30 集合的 Jaccard。
- **P2（是否落在物体上）**：被问物体 patch 上的注意力质量 ÷ 物体的面积占比。
- **P3（模拟命中率）**：
  - 命中 = 被问物体至少保留一个 patch；同时统计物体上保留的 patch 数。
  - 按物体大小分三档：最大实例面积 ≤ 0.33%、0.33%～1.35%、更大。
  - 模拟两种选择方式：全局 top-30、6×6 分块；每种再分别加或不加“去位置”和“排除填充区”。
  - 自检：模拟的强对照（最后一个 token 行 + 去位置 + 分块）必须与实际保留集合相同。
- **剂量**：在实际保留的集合下，按物体上保留的 patch 数（0、1、2～3、≥ 4）分组，统计答 yes 的比例。

- **探索性观察**：只排除填充区（最后一个 token 行 + 分块 + 去位置 + 排除填充区）就到 40.0%，比强对照高约 4.6 个百分点。题目行再加上去，几乎没有额外收益。
- **剂量**（R02 实际保留的集合）：物体上一个 patch 都没保留时，正样本答 yes 的只有 9.7%；保留 1 个时 48.2%，2～3 个时 57.3%，≥ 4 个时 74.9%。
- **当前解释**（AI）：第 1 层文本 token 对图像 token 的注意力（head 平均）主要由图像 token 一侧决定，不随题目变化，换成题目行在 K = 2 下帮不上忙。
- **替代解释**：
  - 题目信息可能在个别 head 里，被 head 平均冲淡；
  - 可能在表示的相似度里，而不在 softmax 权重里；
  - 可能要到更深的层才出现。
  - D2b 逐一检查这三种可能。

### R04：完整 token 的 prefill 记录（开发集）

- **设置**：vanilla LLaVA-1.5-7B，不剪枝，只做 prefill，不生成；全部层用 eager attention，输出 attention 与 hidden states。
- **脚本**：独立脚本 `log_layer_rows.py`，复用 LLaVA 的加载与预处理：vicuna_v1 模板、pad 成正方形、`tokenizer_image_token`，与 `model_vqa_loader` 相同。（2026-10-29 完整阅读补注：仓库里没有 log_layer_rows.py，git log --all 也查不到。R04 实际由 run_eval.py 的 --layer-rows-log 完成（代码 commit 2a75f12，配置 vanilla_layerrows）：_log_layer_rows 包住每次 prefill，同时取出注意力与 hidden states，解码步照常运行；_write_layer_rows 写出 layer_rows.npz；CPU 自检为 check_layer_rows_log.py（12 项）。所以 R04 也写出了答案，与上一条的“不生成”不符，见本文末“偏差”。）
- **每题记录**（float16，压缩保存）：
  - 三段文本对 576 个图像 token 的 head 平均注意力行，在第 0、1、2、4、8、16、31 层。三段是：最后一个 token、题目句的均值、物体名的均值。
  - 题目句均值和物体名均值的逐 head 行，在第 0、1 层（32 个 head）。
  - 每个图像 token 的 hidden state 与物体名各 token hidden state 均值的余弦相似度；再与题目句均值各算一次。用 hidden_states[0]、[1]、[2]，即输入 embedding、第 0 层输出、第 1 层输出，都是 FastV 在第 2 层剪枝之前已有的状态。
- **自检**（不满足就停止排查）：
  - 图像之后的 token id 与 R02 记录的逐题相同；
  - 第 1 层最后一个 token 行与 R02 的差，不超过该行最大值的 1%（R02 的第 0 层用的是 sdpa，这里是 eager，只允许浮点误差）；
  - 用 R04 的行模拟的强对照保留集合，至少 90% 的题与 R02 实际的相同。

### 参与判定的算子

只算在第 2 层之前就能得到的算子，即能用在 FastV 的 K = 2、保留 30 个的设置下。

- **A0**：第 0 层的 head 平均行，物体名、题目句各一个（第 1 层的已在 D2 测过）。
- **H0、H1**：第 0 层、第 1 层上物体对准程度最高的单个 head，物体名、题目句各一个。
  - 物体对准程度即 P2 的比值。
  - head 用两折交叉选择：300 张图按文件名排序，按奇偶分两折；在一折上选比值均值最高的 head，在另一折上计算命中，两折合并。
- **R0、R1**：第 0 层、第 1 层上，逐 head 在 576 个图像 token 上归一化后再平均（每个 head 权重相同），物体名、题目句各一个。
- **C0、C1、C2**：hidden_states[0]、[1]、[2] 上的余弦相似度，物体名、题目句各一个。

### 选择方式、判定与描述项

- **选择方式**：所有算子都用 6×6 分块轮流取，并排除填充区，不去位置。这是 D2 中最好的结构；位置曲线是按最后一个 token 行测的，不用于其他算子。
- **对照**：
  - 强对照：R02 实际的保留集合，≤ 1.35% 上 35.4%；
  - 只排除填充区：最后一个 token 行 + 分块 + 去位置 + 排除填充区，40.0%。
- **判定**（与 DEC-0017 相同）：在开发集面积 ≤ 1.35% 的正样本上，取参与判定的算子中命中率最高的一个。比强对照至少高 10 个百分点（即 ≥ 45.4%）就做 D3，否则换候选 2。同时报告它与“只排除填充区”的差，以及 P1、P2 的对应值。
- **只作描述**（不参与判定）：第 2、4、8、16、31 层 head 平均行的 P1、P2 和模拟命中率，用来看题目相关的注意力从哪一层开始出现。按平均 64 个 token 的预算，K = 2 时保留 30 个；K = 3 时只能保留 11 个；K ≥ 4 时不剪也超过预算。所以这些层不能直接用于同预算的剪枝。

- **判定（v1.1）**：最好的是 C0_o，比强对照高 34.9 个百分点 [29.6, 40.6]（门槛 +10），比只排除填充区高 30.4 [24.9, 36.1]。**通过，做 D3**。
- **只作描述（更深的层，同预算下不能用）**：题目相关的注意力在中间层才出现。
  - 物体名的 head 平均行，第 8 层命中 76.5%（P2 比值 6.75，AUC 0.797，Jaccard 0.371）；
  - 最后一个 token 行，第 16 层 78.5%（P2 7.03，AUC 0.826）；
  - 第 0～2 层的注意力行接近与题目无关（Jaccard ≥ 0.90，P2 第 0、2 层 ≤ 0.93，第 1 层 0.95～0.99）（原写“P2 ≤ 0.93”；2026-10-29 完整阅读补注：第 1 层 head 平均行的 P2 为 0.95（题目句）、0.96（物体名）、0.99（最后一个 token），见 code/output/EXP-0011/d2_coco_dev/d2.md；逐 head 归一化的 R1 为 0.97、0.99，见 d2b_coco_dev_v2/d2b.md）；第 4 层开始出现，第 8～16 层最强，第 31 层又回落（44.6%～51.6%）。
- **当前解释**（AI）：输入层上，LLaVA 的投影把图像 token 放到与词 embedding 可比的空间，物体名的词 embedding 与对应图像区域相近；而前两层的注意力权重主要由图像 token 一侧决定，体现不出这种对应。

## 计划补充（v1.2，2026-10-24，D3 运行之前写定）

### 变体与实现

- **变体**（只按开发集选定）：C0_o + 6×6 分块轮流取 + 排除填充区，不去位置；K = 2，保留 30 个，与强对照同预算。
- **打分**：每个图像 token 的输入 embedding（第 0 层之前的 hidden state）与物体名各 token 输入 embedding 均值的余弦相似度。物体名区间用 `prompt_spans.question_spans`。
- **排除填充区**：按图像原始尺寸，与 `expand2square` 的几何相同，计算 24×24 网格中完全落在填充区的 patch，不让它们被保留。
- **代码**：`fastv_llava.py` 新增 `score_kind="object_cos"` 和 `exclude_padding`；`run_eval.py` 新增 `--fastv-score object_cos`、`--fastv-exclude-padding`；`exp0002.py` 新增两个配置：变体 `fastv64_objcos_strat_nopad`，只排除填充区的对照 `fastv64_prior_strat_nopad`。

  - 面积 ≤ 1.35% 的被问物体至少保留一个 patch 的比例：强对照 41.5%，变体 68.0%（开发集模拟值 70.4%），只排除填充区 44.6%。

- **判读（v1.2）**：判据在原始标注与 RePOPE 下都成立，候选 1 不需要换成候选 2。
- **结论边界**：
  - 只在 POPE（题目点名物体）上检验；
  - 只有 64 档、一个模型；
  - MME 等一般题目上没有定义；
  - 误报增加，在惩罚幻觉的评测上可能吃亏；
  - 新颖性低（检索摘要级）：用文本与视觉 token 的嵌入相似度选择 token，已有 TRIM（COLING 2025，CLIP 文本 embedding）、ReDiPrune（投影前、相关性 + 多样性）、ProViP（关键词与视觉 token 的相似度，未核实）和 CDPruner。
