### 要回答的问题

1. 在第 1 层，题目 token 的注意力行是否随题目变化？是否落在被问的物体上？（P1、P2）
2. 改用题目行打分（加覆盖）时，被问的小物体至少保留一个 patch 的比例，能否明显高于强对照？（P3，离线模拟）
3. 在实际保留的集合下，答 yes 的比例如何随物体上保留的 patch 数变化？（剂量）
4. 顺带记录，供候选 2 使用：第一个回答 token 是 Yes / No 的对数概率。本实验不分析这一项。

### 挑选与评测分开

- **挑选用开发集**：D3 用哪种题目行打分、P3 是否成立，都在开发集上判断。
  - 开发集：COCO val2014 中 POPE 没有用到的图像，随机取 300 张。
  - 出题方式与 POPE 相同：每张图 3 道 yes、3 道 no，共 1800 题（`make_coco_dev.py`，种子 0）。
  - 两个文件的 sha256：题目 b70efa02…，标签 14fe106d…。
  - 标签来自 COCO 标注，会漏标一些物体（F27）。用来比较打分规则可以，不用来报告准确率。
- **POPE 只做两件事**：机制描述（统计口径与开发集相同），以及 D3 的最终评测。

### 离线统计

R02、R03 各算一遍，口径相同。

- **三种打分**：
  - 最后一个 token 那一行（FastV 原样）；
  - 题目句（“Is there a X in the image?”）各 token 行的均值；
  - 物体名各 token 行的均值。
- **P1（与题目的关系）**：同一张图、不同题目时，top-30 集合的 Jaccard。
- **P2（是否落在物体上）**：被问物体 patch 上的注意力质量 ÷ 物体的面积占比。
- **P3（模拟命中率）**：
  - 命中 = 被问物体至少保留一个 patch；同时统计物体上保留的 patch 数。
  - 按物体大小分三档：最大实例面积 ≤ 0.33%、0.33%～1.35%、更大。
  - 模拟两种选择方式：全局 top-30、6×6 分块；每种再分别加或不加“去位置”和“排除填充区”。
  - 自检：模拟的强对照（最后一个 token 行 + 去位置 + 分块）必须与实际保留集合相同。
- **剂量**：在实际保留的集合下，按物体上保留的 patch 数（0、1、2～3、≥ 4）分组，统计答 yes 的比例。

### 预测与判读

在开发集（R02）上判断。

| 编号 | 预测 |
| --- | --- |
| P1 | 题目行的同图不同题 Jaccard，比最后一个 token 行至少低 0.1 |
| P2 | 题目行“物体上的注意力质量 ÷ 面积占比”大于 1，并且高于最后一个 token 行 |
| P3 | 在面积 ≤ 1.35% 的正样本上，最好的“题目行 + 分块”模拟命中率，比强对照（最后一个 token 行 + 去位置 + 分块）至少高 10 个百分点 |

- P1、P2 不成立：说明第 1 层的注意力主要由 key 决定，换成题目行也帮不上忙。
- P3 不成立：说明候选 1 在 K = 2 下的上限有限。
- 以上任一情况：回到 2a，换层或换算子再诊断一次；仍不成立，按 DEC-0017 换候选 2。
