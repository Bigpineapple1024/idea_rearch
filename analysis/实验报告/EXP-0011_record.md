### 离线统计

R02、R03 各算一遍，口径相同。

- **三种打分**：
  - 最后一个 token 那一行（FastV 原样）；
  - 题目句（“Is there a X in the image?”）各 token 行的均值；
  - 物体名各 token 行的均值。
- **P1（与题目的关系）**：同一张图、不同题目时，top-30 集合的 Jaccard。
- **P2（是否落在物体上）**：被问物体 patch 上的注意力质量 ÷ 物体的面积占比。
- **P3（模拟命中率）**：
  - 命中 = 被问物体至少保留一个 patch；同时统计物体上保留的 patch 数。
  - 按物体大小分三档：最大实例面积 ≤ 0.33%、0.33%～1.35%、更大。
  - 模拟两种选择方式：全局 top-30、6×6 分块；每种再分别加或不加“去位置”和“排除填充区”。
  - 自检：模拟的强对照（最后一个 token 行 + 去位置 + 分块）必须与实际保留集合相同。
- **剂量**：在实际保留的集合下，按物体上保留的 patch 数（0、1、2～3、≥ 4）分组，统计答 yes 的比例。

| P1：题目行的同图不同题 Jaccard 比最后一个 token 行至少低 0.1 | 最后一个 token 行 0.959；题目句均值 0.980（反而更高）；物体名均值 0.931，只低 0.028 [0.023, 0.034] | 不成立 |

- **探索性观察**：只排除填充区（最后一个 token 行 + 分块 + 去位置 + 排除填充区）就到 40.0%，比强对照高约 4.6 个百分点。题目行再加上去，几乎没有额外收益。
- **剂量**（R02 实际保留的集合）：物体上一个 patch 都没保留时，正样本答 yes 的只有 9.7%；保留 1 个时 48.2%，2～3 个时 57.3%，≥ 4 个时 74.9%。
- **当前解释**（AI）：第 1 层文本 token 对图像 token 的注意力（head 平均）主要由图像 token 一侧决定，不随题目变化，换成题目行在 K = 2 下帮不上忙。
- **替代解释**：
  - 题目信息可能在个别 head 里，被 head 平均冲淡；
  - 可能在表示的相似度里，而不在 softmax 权重里；
  - 可能要到更深的层才出现。
  - D2b 逐一检查这三种可能。

### R04：完整 token 的 prefill 记录（开发集）

- **设置**：vanilla LLaVA-1.5-7B，不剪枝，只做 prefill，不生成；全部层用 eager attention，输出 attention 与 hidden states。
- **脚本**：独立脚本 `log_layer_rows.py`，复用 LLaVA 的加载与预处理：vicuna_v1 模板、pad 成正方形、`tokenizer_image_token`，与 `model_vqa_loader` 相同。
- **每题记录**（float16，压缩保存）：
  - 三段文本对 576 个图像 token 的 head 平均注意力行，在第 0、1、2、4、8、16、31 层。三段是：最后一个 token、题目句的均值、物体名的均值。
  - 题目句均值和物体名均值的逐 head 行，在第 0、1 层（32 个 head）。
  - 每个图像 token 的 hidden state 与物体名各 token hidden state 均值的余弦相似度；再与题目句均值各算一次。用 hidden_states[0]、[1]、[2]，即输入 embedding、第 0 层输出、第 1 层输出，都是 FastV 在第 2 层剪枝之前已有的状态。
- **自检**（不满足就停止排查）：
  - 图像之后的 token id 与 R02 记录的逐题相同；
  - 第 1 层最后一个 token 行与 R02 的差，不超过该行最大值的 1%（R02 的第 0 层用的是 sdpa，这里是 eager，只允许浮点误差）；
  - 用 R04 的行模拟的强对照保留集合，至少 90% 的题与 R02 实际的相同。

### 参与判定的算子

只算在第 2 层之前就能得到的算子，即能用在 FastV 的 K = 2、保留 30 个的设置下。

- **A0**：第 0 层的 head 平均行，物体名、题目句各一个（第 1 层的已在 D2 测过）。
- **H0、H1**：第 0 层、第 1 层上物体对准程度最高的单个 head，物体名、题目句各一个。
  - 物体对准程度即 P2 的比值。
  - head 用两折交叉选择：300 张图按文件名排序，按奇偶分两折；在一折上选比值均值最高的 head，在另一折上计算命中，两折合并。
- **R0、R1**：第 0 层、第 1 层上，逐 head 在 576 个图像 token 上归一化后再平均（每个 head 权重相同），物体名、题目句各一个。
- **C0、C1、C2**：hidden_states[0]、[1]、[2] 上的余弦相似度，物体名、题目句各一个。

### 选择方式、判定与描述项

- **选择方式**：所有算子都用 6×6 分块轮流取，并排除填充区，不去位置。这是 D2 中最好的结构；位置曲线是按最后一个 token 行测的，不用于其他算子。
- **对照**：
  - 强对照：R02 实际的保留集合，≤ 1.35% 上 35.4%；
  - 只排除填充区：最后一个 token 行 + 分块 + 去位置 + 排除填充区，40.0%。
- **判定**（与 DEC-0017 相同）：在开发集面积 ≤ 1.35% 的正样本上，取参与判定的算子中命中率最高的一个。比强对照至少高 10 个百分点（即 ≥ 45.4%）就做 D3，否则换候选 2。同时报告它与“只排除填充区”的差，以及 P1、P2 的对应值。
- **只作描述**（不参与判定）：第 2、4、8、16、31 层 head 平均行的 P1、P2 和模拟命中率，用来看题目相关的注意力从哪一层开始出现。按平均 64 个 token 的预算，K = 2 时保留 30 个；K = 3 时只能保留 11 个；K ≥ 4 时不剪也超过预算。所以这些层不能直接用于同预算的剪枝。
