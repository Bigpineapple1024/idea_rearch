# 单次实验报告

每个实验保存：
- EXP-0001_record.md：基于 [EXPERIMENT_RECORD](../templates/EXPERIMENT_RECORD.md)，记录实际事实。
- EXP-0001_squeeze.md：基于 [SQUEEZE_REPORT](../templates/SQUEEZE_REPORT.md)，分析边界、机制和下一步。

编号仅为示例，当前没有实际记录。原始产物放 code/output/<实验ID>/<运行ID>/，登记校验和与可恢复备份。

先保存事实，再做分析，不覆盖原始证据。完成后更新总表、现象、素材、最新报告入口和索引。
