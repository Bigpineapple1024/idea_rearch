## 4. 解释与不确定性

- **最支持的解释**：
  - 水平部分是误差的大块（16%～55%）。
  - 模型对未来窗口水平变化的预测很弱（相关 ≤ 0.55），大部分水平误差来自没被预测到的真实变化，而不是“预测了错误方向的变化”。
  - 所以把预测变化收缩到 0 没有用（除 ETTh1 测试期外）；真正的余地在“更好地预测水平变化”。
- **仍可成立的替代解释**：只用 96 步输入，水平变化本来就预测不了（MODE_C-0003 的 M1）。如果是这样，任何方法都只能小幅改善。
- **不支持的强结论**：
  - “学到的水平变化在所有数据集上有害”（被否定）；
  - “收缩是改进方向”（只有 1 个组合，且不稳）。

## 5. 知识沉淀

- **新现象 F-TS13**：iTransformer 几乎预测不出窗口水平的变化。四个数据集、验证期与测试期都一样：斜率不超过 0.29，相关不超过 0.55，都随预测长度下降；水平部分占 MSE 的 16%～55%。
- **新现象 F-TS14**：验证期与测试期的难度关系因数据集而异。ETTh1、ETTm1 的验证期更难（MSE 是测试期的 1.1～3.1 倍），ETTh2（720 档除外）、ETTm2 的验证期更容易；验证期的水平占比在四个数据集上都接近一半。
- **修正 F-TS10**：只在 ETTh1 的测试期（192 / 336 / 720 档）和 ETTm1-720 的测试期成立，不跨数据集；按规则只登记为现象。
- **已回答**：EXP-0009 的三个问题都有了答案（见记录）。
- **更新位置**：已发现的实验现象；MODE_C-0003 回流；第 ⑦ 步排序。

## 6. 下一步决策

1. **最优先的低成本检查**（第 ⑦ 步的候选诊断，只用 CPU）：用简单的统计量预测器，从输入段的统计量线性回归未来窗口的均值，只在训练期上拟合，看它对水平变化的相关能否明显高于 iTransformer。如果能，“显式预测未来统计量”（SAN / FAN 方向）有空间。
2. **若结果保持不变**（简单预测器也只有 iTransformer 的水平）：水平变化在 96 步输入下基本不可预测，水平方向的成功可能性降为低。
3. **收缩方向**：不再追加运行。
