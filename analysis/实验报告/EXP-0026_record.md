### 选择规则（写定）

- **候选**：覆盖 16（K = 2，EXP-0024-R18、R17）、覆盖 8（K = 2）、覆盖 16（K = 1）。
- **主指标**：Δ = 候选 − K = 2 路由（IDEA-0003 的方法，EXP-0024-R02、R03），即全部题准确率的配对差，两个开发集分别计，取平均 Δ̄。
- **选法**：选 Δ̄ 最大的候选。与最大值相差不到 0.1 的，按此顺序取第一个：覆盖 16（K = 2）、覆盖 8（K = 2）、覆盖 16（K = 1）。

### 判读（写定）

- **覆盖的增益** Δc = 所选 − 同 K 的路由，两个开发集分别计。
- **定位的增益** Δl = 所选 − 同 K 的居中框覆盖，取两集平均。所选为覆盖 8 时，用 K = 2 的“覆盖 16 − 居中框覆盖 16”，并写明这一限制。
- **有希望（进入确认）**：Δc 在两个开发集上都 > 0，且 Δl > 0。
- **集中而非定位**：Δc 都 > 0，但 Δl ≤ 0。增益来自把名额集中到图像中部的一块，不需要题目定位；记录后请用户决定是否继续（这时新颖性更低）。
- **不像**：三个候选的“− 同 K 路由”的两集平均都 ≤ 0。
- **中间情况**：其余情形，交用户决定。

### 归因规则（写定，不改选择规则与判读）

- **区域还是逐 token 相关性**：Δr = 覆盖 16（K = 2）− 不围框（R11、R12），取两集平均。
  - Δr > 0：按区域多留比按 token 相似度多留更好，写成“区域的作用”；
  - Δr ≤ 0：增益来自题目相关的 token 本身，不需要框，论文按此写。
- **同时报告**：A′+B+V（每题都用）− 路由，即不路由的题改用逐 token 的题目查询；覆盖 16 − A′+B+V。

### 仍缺的对照（记下，本实验不做）

- 用 A 自己的注意力围框（RoRA 式），区分“按题目定位”与“按显著性定位”：要在剪枝层内部取框，改动较大。
- 随机框、按真实物体框的上界框；挪入个数与框边长的扫描（+24、边长 8～16）。
- 把覆盖加在一个更强的、在 LLM 之前剪枝的方法上（VisionZip、DivPrune）。查新指出：64 个 token 时 GridPrune、CDPruner、FSR 报告的 GQA 为 58.2～58.7，比本项目的路由（GQA testdev 55.47）高约 3 分，只在 FastV 一族上验证不足以支持“大提升”。
