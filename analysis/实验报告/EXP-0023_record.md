## 计划（v1，计算之前写定）

### 问题

路由把开放式题（VQAv2 的 other 类）全部交给强对照 A，方法对这一半题目没有作用；64 档上 other 类比 vanilla 低约 10 分，比 VisionZip-64 低约 4 分（F43）。考虑两种新模块：

- **邻域法（模块 A）**：用题目查询定位被点名的物体，再把名额给物体及其周围一圈（越近越密）。可借鉴：文本问答的“段落窗口”、人眼的中央凹采样。
- **放大法（模块 B）**：在被点名物体周围裁一块重新编码，用放大后的细节 token 替换一部分名额。可借鉴：主动视觉的“先定位、再放大”。

本诊断要回答：哪一种更可能成功？两种都不像时，退回“把剪掉的 token 合并成上下文 token”（方向 2，不依赖本诊断）。

### 数据（只用开发用的数据，test2 与 GQA 不用）

- **test1**：VQAv2 val 子集，5246 题、1000 张图，已有 EXP-0018 的运行（A-64 R02、A′+B+V-64 R03、VisionZip-64 R05、vanilla R09）。test1 已用于选路由规则，本诊断仍是事后探索。
- **dev**：VQAv2 val 在 coco_dev 300 张图上的 1485 题（`vqav2_dev`），没有模型运行，只做只看标注的统计（N1）。
- **不用**：test2（EXP-0020，路由的确认集）与 GQA（EXP-0022），留作以后新模块的确认，不让它们参与设计。
- 物体位置：COCO instances_val2014 的框，映射到 LLaVA 补成正方形后的 24×24 网格，被覆盖 ≥25% 的 patch 算物体 patch（与 analyze_object_boxes.py、squeeze_0018_boxes.py 相同）。题目点名的物体用 squeeze_0018 的词表匹配（含 man、woman、people → person 等）。

### 题目子集

- **S_open**：answer_type 为 other、题目点名了图中有标注的 COCO 物体（“话题物体”）。
- **S_rel**（S_open 的子集）：多数人答案也是一个图中有标注的 COCO 类别，且不同于话题物体。例如“what is the man holding” → frisbee。这类题的答案位置可以从框得到。
- **S_attr**（S_open 的子集）：颜色题（question_type 以 “what color” 开头），答案在话题物体自身上。

### 测量

- **N1（test1、dev，只看标注）**：在 S_rel 上，答案物体的 patch 相对话题物体的位置。环 r = 到话题物体 patch 的切比雪夫距离为 1～r 的 patch，不含物体本身。逐题归为三类：
  - **内部**：答案 patch 至少一半在话题物体内；
  - **邻近**：否则，至少一半在话题物体加 2 格环内；
  - **远处**：其余。
  报告三类的比例。
- **N2（test1，64 档）**：在 S_open 上，A 与 A′+B+V 的 30 个保留 token 分别有几个落在话题物体内、2 格环内、其他位置；在 S_rel 上另算落在答案物体上的个数。按 Δ环 = A′+B+V 环内个数 − A 环内个数（< 0、= 0、> 0）分组，看 A′+B+V − A 的 VQA 分数差；S_rel 上按 Δ答案（同理）分组。
- **N3（test1，64 档）**：在 S_attr 与 S_open 上，按话题物体上保留的 token 数（0、1～3、≥4）分组，报告 A、A′+B+V 的准确率，并与 vanilla、VisionZip-64 对照。

配对差按图像重抽 1000 次，种子 0。

### 判读规则（写定）

- **邻域法有希望**，需要两条同时满足：
  - ① N1：test1 与 dev 上，S_rel 的“邻近”比例都 ≥ 40%，并且高于“内部”比例；
  - ② N2：S_open 上 Δ环 < 0 组的 A′+B+V − A 低于 Δ环 ≥ 0 组（点估计，描述性）。
- **邻域法不像**：N1 的“远处”比例 ≥ 50%，即答案物体多半离话题物体很远，局部名额帮不上。
- **放大法有希望**：
  - N3 中，S_attr 上的准确率随话题物体上保留的 token 数单调上升（剂量）；
  - 而且 A 在 S_attr 上比 vanilla 低 ≥ 5 分。
- **两者都不像**：退回方向 2（上下文合并）。
- 无论结果如何，这些都是**事后探索**。据此设计的模块要先在开发集上调，再在新数据上预注册确认（例如新抽的 VQAv2 test3 与 GQA），才能成为论文的结论。
