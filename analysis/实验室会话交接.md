# 实验室会话交接

写给在实验室电脑上新开的 Claude Code 会话。新会话**不会继承**云端会话（2026-10-23）的对话记忆，所有进度都以本仓库的文档为准。先读本文件，再按 AGENTS.md 的顺序读其余文档。

## 一、怎么开会话

1. **装 WSL2（Ubuntu）**，在 WSL 的 Linux 文件系统里克隆仓库（例如 `~/idea_rearch`），不要放在 `/mnt/c` 或 `/mnt/d` 下。
2. **登录 GitHub**：`gh auth login`，或配置 SSH key。之后 Claude Code 每次提交都会立即推送；这里用的是本机的 git 账号，与云端会话的权限无关。
3. **启动**：在仓库目录运行 `claude`（或用 Claude Desktop 打开该文件夹）。想在手机或网页的 Claude Code 应用里查看，运行 `claude remote-control`。
4. **分支**：`main` 放文档和论文；实验在 `code/token-pruning`、`code/ts-forecasting` 上进行（见[研究流程](研究流程.md)“分支与提交”）。

## 四、第一次会话按顺序做

1. **环境检查**：
   - `nvidia-smi`，把显卡、显存、驱动、CUDA 版本写进 paper-plan 的“算力”一栏；
   - 安装 conda；
   - 按 code/README 建环境。
2. **外部仓库**：按 [source/README](../source/README.md) 中的 commit 克隆到 `source/`。
3. **自检**：
   - `code/token_pruning/smoke_test.py`；
   - `code/token_pruning/check_fastv_equivalence.py`；
   - `code/ts_forecasting/probe_duet_mask.py`。
4. **视觉 token 剪枝 EXP-0002**（切到 `code/token-pruning`）：
   - 下载 `liuhaotian/llava-v1.5-7b` 和 `openai/clip-vit-large-patch14-336`；国内可设 `HF_ENDPOINT=https://hf-mirror.com`。
   - 按 LLaVA `docs/Evaluation.md` 准备 POPE（需要 COCO val2014）和 MME。
   - 先跑 vanilla，确认 POPE 85.9、MME 1510.7 相差不超过 1 个点。
   - 再跑 FastV 三档预算（`code/token_pruning/run_pope_mme.sh`），然后是 VisionZip、SparseVLM（v1.5 分支，batch 1）和同预算随机剪枝。
5. **时序预测**（切到 `code/ts-forecasting`）：
   - 下载 TFB 预处理数据（DUET README 中的 Google Drive / 百度网盘链接），并与 `to_tfb_format.py` 转换出的 ETTh1 逐值比对；
   - DUET 在 ETTh1 上补种子 2023，并扩展到 ETTh2/ETTm1/ETTm2；
   - TQNet、WPMixer 在统一协议下重跑（WPMixer 用全部窗口计分）。
6. **每个实验结束后**：
   - 用 `/record-experiment` 写记录；
   - 用 `/squeeze-experiment` 写深挖报告；
   - 同步结果总表、现象台账、论文素材库和最新报告入口；
   - 提交并推送。
7. **补做**：EXP-0001、EXP-0003 的 squeeze。
8. **论文全文**：
   - 下载 6 篇论文的 PDF 到 `papers/`，用 MinerU 解析到 `literature/processed/`；
   - 用 `/analyze-paper` 补全论文笔记中标为“待回查”的 SC 条目；
   - 实查 FastV、DUET 等的引用量，写明查询日期。

## 五、已知问题

- FastV 官方 KV-cache 版在 eager 注意力下会报错，必须打 rotary 补丁，而且会重复写入 KV cache；用本项目的 `fastv_llava.py` 可以避免这些问题。
- VisionZip 不要用 `pip install visionzip`：PyPI 包里没有代码。要传入论文的预算 (54,10)/(108,20)/(162,30)，默认值 (191,30) 不是论文设置。
- SparseVLM 只能用 batch size 1；脚本路径写死为作者集群路径，需要先修改。
- WPMixer 官方测试 `drop_last=True`，超参数是在测试集上调出来的；对比时用全部窗口计分。
- DUET 测试时通道 mask 随机，但影响很小；种子之间的波动较大，至少跑 3 个种子。
- 在依赖较多的环境里装包时，setuptools 可能被升级而缺少 `pkg_resources`，WPMixer 内置的 pytorch_wavelets 依赖它；出现这个报错时执行 `pip install "setuptools<70"`。
