## 候选详情

### T1 多模态大模型视觉 token 剪枝 / 压缩

- **问题**：视觉 token 数量大（LLaVA-1.5 为 576 个），推理开销高。
- **代表 baseline**：FastV（第 2 层后按视觉-文本注意力剪枝）、SparseVLM（文本引导，ICML 2025）、VisionZip（视觉编码器端保留主导 token 并合并其余，CVPR 2025）。VisionZip 自报 576→64 token 时保留 94.0% 性能，FastV 为 75.6%，SparseVLM 为 85.8%。
- **可切入的现象**：Findings of ACL 2025 的 “Are We Solving the Right Problem?” 报告 FastV、SparseVLM 在部分数据集上不如随机丢弃或池化，并指出注意力重要性分数存在位置偏差；“Stop Looking for Important Tokens” 同样指出靠近末尾的 token 注意力偏高，并认为重复性比重要性更关键。
- **入口模式**：Pattern 2 现象驱动 / Pattern 3 假设挑战（“注意力分数能代表 token 重要性”）。
- **题目示例**：面向多模态大模型推理加速的位置偏差感知视觉 token 剪枝方法研究。
- **最小验证**：LLaVA-1.5-7B + 若干 benchmark；比较 FastV、随机剪枝和去偏后的剪枝，统一 token 预算，报告准确率、FLOPs 与延迟。
- **风险**：方法极多，须先确认去偏思路是否已被 2025–2026 工作覆盖。

### T2 多模态大模型幻觉的免训练缓解

- **问题**：模型生成图中不存在的物体或属性。
- **代表 baseline**：VCD（对比原图与扰动图的输出分布）、OPERA（抑制对 anchor token 的过度关注）、TARAC（2025，将幻觉归因于生成中图像注意力衰减，自报 CHAIR 上 CS 比 VCD 降低 25.2）、MDSAM、CAAC（WACV 2026）。
- **可切入的现象**：生成过程中对图像 token 的注意力随长度衰减。另外，不同论文的 VCD、OPERA 数字依赖模型、POPE/CHAIR 设置和解码超参，彼此不可直接比较。
- **入口模式**：Pattern 2 现象驱动；统一设置下的重新评估可作为论文中的分析章节。
- **题目示例**：基于视觉注意力动态分析的多模态大模型幻觉缓解方法研究。
- **最小验证**：LLaVA-1.5-7B，POPE + CHAIR（可加 AMBER），在同一解码设置下复现 VCD 与一种注意力干预方法。
- **风险**：OPERA 的 beam search 显存与时间开销较大；需要额外检查改进是否只来自解码超参。

### T3 大语言模型长上下文 KV cache 压缩

- **代表 baseline**：SnapKV（观察窗口 + 池化选择 KV 位置）、PyramidKV（COLM 2025，低层多、高层少的分层预算，自报 12% 缓存接近全量）、DynamicKV、ChunkKV（按语义块保留）。
- **评价**：LongBench、Needle-in-a-Haystack。
- **算力**：Llama-3-8B / Qwen2.5-7B 在 32k 上下文下 KV 约数 GB，单卡可行；更长上下文需要量化或缩小模型。
- **题目示例**：面向任务与注意力头差异的自适应 KV cache 压缩研究。
- **风险**：工程细节较多（自定义 attention kernel），需要能读改 transformers 源码。

### T4 CLIP 免训练测试时自适应

- **代表 baseline**：TPT（需反传，开销大）、TDA（CVPR 2024，键值缓存，免训练）、BoostAdapter（NeurIPS 2024，区域自举样本）、MS-TTA（kNN mean-shift 利用全部测试样本，2026 年更新）、UL-TTA（只调 logit 级参数）。
- **可切入的现象**：现有免训练方法依赖高置信样本，低置信样本未被利用（MS-TTA 作者的表述）。
- **算力**：CLIP ViT-B/16 推理，单卡数小时可跑完 ImageNet 变体及 10 个细粒度数据集。
- **评价**：适合以毕业为主要目标，实验快、可做充分消融；天花板与顶会新颖性有限。

### T5 SAM 辅助的半监督医学图像分割

- **代表 baseline**：SemiSAM（分割模型输出作为 SAM 提示，SAM 伪标签反哺训练）、SAMatch（自报 ACDC Dice 89.36%）、SFR（自报 LA 上 1 例标注时 Mean Teacher Dice 从 29.68% 提升到 74.40%）。
- **数据**：ACDC、LA 等公开数据集。
- **评价**：传统且可落地的修士题目，单卡可训练；需要确认 2025–2026 的最新工作，同质化较严重。

### T6 长期时间序列预测（不优先）

2025 年的立场论文 “There are no Champions in Long-Term Time Series Forecasting” 在统一设置下重跑后发现没有模型在所有数据集上都获胜，模型间差异较小。算力最省，但难以证明方法带来稳定提升。

### X1 小模型 GRPO 强化学习推理（不建议）

代表工作在 4 张 48GB A40 上训练 1.5B 模型，并因资源限制压缩了采样数与生成长度；单张 24GB 显卡只有社区非受控案例，1 年毕业风险高。

## 建议与下一步

1. 首选在 T1 / T2 中选一个：两者都免训练、用 LLaVA-1.5-7B 即可开展，且都有已发表的反直觉现象可做机制分析；T4 / T5 作为稳妥备选。
2. 选定后为该方向收集 5–8 篇核心论文（上述 baseline + 2025–2026 最新工作），逐篇使用 analyze-paper，存入 analysis/论文笔记/。
3. 使用 deep-read（Mode C）构建 P×F 矩阵，再用 discover-innovation 输出 IDEA_PACKAGE，并完成新颖性检索。
4. 同步复现 1 个 baseline，固定 commit、模型权重与评价脚本。

粗略时间线（推断，按 12 个月）：1–2 月 读论文与复现；3–6 月 机制分析与方法迭代；7–9 月 消融、泛化与补实验；10–12 月 写作与答辩。
