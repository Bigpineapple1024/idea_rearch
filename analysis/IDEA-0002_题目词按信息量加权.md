## A：当前领域

- **具体问题**：EXP-0011 的变体按“图像 token 的输入 embedding 与物体名 embedding 的余弦”选择，POPE F1 从 64.66 升到 83.63（F29）。但物体名要靠 POPE 的固定句式找出（`prompt_spans.question_spans`），一般题目没有这个结构（P8）。
- **算子**：查询向量 q。直接用题目全部 token 的均值时，模板词（Is、there、in、the、image、Answer the question using a single word or phrase、ASSISTANT:）占了绝大多数 token，q 偏向模板词；D2b 中题目句均值的命中只有 40.0%。
- **代价**：方法只能用在点名物体的题目上，第 ⑫ 步的普遍性检查（至少两个 benchmark）做不了。

## B：方法来源（信息检索的词权重理论）

- **原文位置**：Lee，IDF Revisited（SIGIR 2007，arXiv 0705.1161，ar5iv 全文已读），复述并推导了 Robertson–Spärck Jones（RSJ）权重与 Croft–Harper 的推导；Robertson 的说明页（staff.city.ac.uk/~sbrp622/idf.html）。Spärck Jones 1972 与 Robertson 2004 的原文 PDF 未读（需下载许可）。
- **原始问题**：检索时，查询里在很多文档中都出现的词区分不了相关与不相关的文档，不应和少见的词同样计权。
- **有效机制**：RSJ 权重 log[p(1−q)/(q(1−p))]（p、q 是词在相关、不相关文档中出现的概率）。没有相关性信息时，Croft–Harper 用两条假设把它化成 IDF：
  - CH-1：语料中大多数文档与查询无关，所以 q ≈ df/N；
  - CH-2：所有查询词在相关文档中出现的概率相同。
  - 结果是 log((N − df)/df) 加常数；Lee 的推导给出 log(1 + N/df)。
- **真正起作用的部分**：权重只由“这个词在多少文档里出现”决定；出现在所有文档里的词权重为 0。
- **必要条件**：①有一个与当前查询大多无关的文档集合，用来估计 df；②查询是词的集合（词之间独立）；③加权后的组合方式要能体现每个词的贡献（检索里是加权求和）。

## C：迁移案例

| 案例 | 怎么用 B | 输入输出 / 结构的改动 | 生效证据与限制 | 核对状态 |
| --- | --- | --- | --- | --- |
| BERTScore（Zhang 等，ICLR 2020，arXiv 1904.09675） | 两段文本的 token embedding 做余弦匹配，每个 token 的匹配分按 IDF 加权 | IDF 在测试语料（参考句）上算，不用标签；加一平滑 | 图像描述评价上明显有效（0.917 对 0.888），机器翻译上时好时坏；作者认为效果取决于文本领域 | ar5iv 全文已读第 3、5 节 |
| SIF（Arora 等，ICLR 2017） | 句向量 = 词向量的加权平均，权重 a/(a + p(w))，再减去共同成分 | 把“按频率降权”用在 embedding 平均上 | 文本相似度任务（原文未读） | 只读了代码仓库说明；原文需下载许可 |
| CLIP Surgery（Li 等，arXiv 2304.05653） | 图文相似度图减去各类别共有的成分 | 视觉-语言 embedding 上的“共同成分去除” | 可解释性与多标签识别上有效；只有一个文本时用空字符串代替 | ar5iv 全文已读第 3.3 节 |

- **B 与 C 的对比**：BERTScore 直接用 IDF、只改了“文档”的定义（测试语料中的句子）；SIF 把 IDF 换成平滑的频率倒数，并加了共同成分去除。两者都把 IDF 从“文档打分”搬到了“embedding 的加权组合”，这是本方案要做的同一件事。
- **哪些是生效的必要条件**：embedding 与匹配对象要在可比的空间里（BERTScore 用同一个 BERT；本项目的 F29、M11：LLaVA 的投影让图像 token 与词 embedding 可比）。

## 预测、成功与停止

- **POPE**：A′+B 接近物体名查询（差不超过 2 个点，“an”/“imange” 题会稍差），明显高于 A′ 与 A；A+B 与 A 相差不超过 1 个点（F28：第 1 层注意力不看题目）。
- **MME**：方向不确定。被问物体明确的子任务（existence、count、position、color）预计好于 A；名字类（celebrity、artwork、landmark、posters）与文字类（OCR、text translation）可能更差。
- **成功**：POPE 上 A′+B − A′、A′+B − A 的配对区间都在 0 以上（原始标注与 RePOPE）；MME-P 上 A′+B − A 的区间不在 0 以下。两者都满足，才算“在两个 benchmark 上整体指标稳定提升（POPE）且不变差（MME）”。
- **停止 / 回退**：POPE 上 A′+B 不高于 A′ → B 在本系统中无效，回到第 ⑨ 步换方法（例如 SIF 的共同成分去除）。MME-P 明显低于 A → 方法限定在“点名物体的题目”，第 ⑫ 步改为检查按题目类型切换。
- **独立复验**：换预算（128）与第二个一般题目的 benchmark（需要下载，待用户许可）。
