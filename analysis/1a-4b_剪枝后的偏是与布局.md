当前可靠认识：缺口与编号是两件事（编号管“在哪里”，缺口管是 / 否的门槛）；填满缺口（不论内容）消除偏“是”；fill 的作用是让剪枝后的模型回到不剪枝的行为。仍属推断：偏“是”的算子级机制（注意力里图像 key 的位置分布 → 反面证据）。

## 新发现、下一轮追问与最小验证

1. **直接测注意力**（最小验证，CPU / 少量 GPU）：同一批“否”题上，CDPruner-64、orig、fill、shuffle、mass 每层文字 query 给图像 key 的注意力总量与在位置上的分布；预测：orig、mass 的分布与不剪枝最不像，fill、shuffle 最像。
2. **最便宜的填法**：缺口里放所有保留 token 的平均，或一个固定的 key / value，是否也消除偏“是”？shuffle 的结果预测“是”；若成立，偏“是”的根因就是“位置上有没有 key”，与内容无关，fill 的内容只为空间题服务。
3. **选法的作用**：DivPrune（不看题目）上 fill 是否同样回到不剪枝（EXP-0043 的 Q1，与 EXP-0045 的 A 部分）；CDPruner 的相关性归一化是否是偏“是”的来源之一（C39）。
4. **按研究流程第二章找领域 B**：底层问题可以写成“注意力序列里一部分位置的 token 缺失时，如何让下游像看到完整序列一样工作”。候选领域（未检索，待查原文）：掩码图像建模（MAE 的解码器在被遮住的位置放共享的 mask token、恢复完整布局再解码）、语音与时序的缺失值处理、长上下文 LLM 的 KV 缓存驱逐与位置插值。要查的是：它们怎样在缺失的位置上放东西、需要什么条件才有效（例如 mask token 是训练出来的，本流程免训练），再看有没有领域 C 把它用到免训练的推理里。
5. **评价方法**：报告 POPE 时同时给答“是”的比例与对不剪枝的差（C42）；文献里剪枝在 POPE 上高于不剪枝的报告（CRISP、CoverPruner、arXiv 2604.12035 里 CDPruner-64 的 88.0 对 87.0）可能部分来自偏“是”，需核对。

- 回退：若别的底座上 fill 不再有增益，fill 只是 CDPruner-64 上的现象，论文改以“缺口与编号的分离（F107、F108）”和“偏‘是’的评价问题（P23）”为分析贡献。
- 停止追问的条件：注意力测量（第 1 条）与最便宜的填法（第 2 条）都与 2b 一致时，因果链的中间环节算有了直接证据。
