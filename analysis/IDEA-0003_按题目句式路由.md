## 要解决的问题（P11）

题目点名的物体是题目的话题，不一定是答案所在（术语按文献检索修正：经典问答里的 focus 指答案所指的部分，被点名的物体是题目的话题）（2026-10-25 原文核对补注：这一区分不能以问答文献为出处。Moldovan 等的 focus 定义是“题目在找什么”，但其 Table 1 在 where、when、how 题中常把被点名的实体标为 focus；Lally 等未读。本项目改用自己的描述：题目点名的物体不一定是答案所在的区域；“话题”只作描述性用语，不再借用 focus 一词，[领域 B 原文核对](论文笔记/domainB_原文核对_LiRoth_Moldovan.md)）。A′+B+V 把一部分名额按“像不像题目词”分给图像 token：

- 答案就是被点名物体本身（在不在、有几个）时有用：VQAv2 上 is there (a) +7.6、+10.7，how many +3.3；POPE 三档都显著；
- 答案是被点名物体的属性、动作、位置或旁边的东西时有害：what is the man −16.6，where is the −8.4，what is the −7.8；点名图中物体的 other 题合计 −5.14 [−7.41, −2.96]。

两者相抵，VQAv2 64 档总差 −0.74（差异不显著，F38）。S4 已排除“分块轮流取浪费名额”的解释（H-forced）：查询选的 token 落在物体内时，other 类反而损失更大（F39）。可视性加权分不开这几类题：三类题的查询占比是 0.55～0.58（S2）。

## 方法

- **路由规则**：题目（图像之后的第一行文字）以助动词开头（is、are、does、do、did、can、could、was、were、has、have、had、will、would、should、shall、may、might、must）或以“how many”开头时，用 A′+B+V；其他题用 A（强对照 + 排除填充区）。
- 只看题目文字，不看标签、图像或模型输出；在选择之前决定，不增加计算。
- 实现：`--fastv-route yesno_howmany`（fastv_llava.py 的 `route`）。不路由的题走与 A 完全相同的打分路径，路由的题与 A′+B+V 完全相同（check_route.py 核对）。
- **在已有 benchmark 上的含义**：POPE 的 8910 题与 MME 十个感知子任务的 2114 题全部是助动词开头（check_route.py）。所以 POPE 与 MME-P 上路由 = A′+B+V，已有结果不变：POPE 三档显著提升，MME-P 三档差异不显著。只有 MME 的两个认知子任务里有 118 题不路由。

## B：方法来源（问答系统的题目分类）

- 经典开放域问答先按“期望的答案类型”给题目分类，再按类别选择检索与抽取策略。例如 Li & Roth（COLING 2002，Learning Question Classifiers）的粗、细两级答案类型；TREC 问答系统在题目分析阶段确定 focus（答案所指的部分）与答案类型（Moldovan 等，ACL 2000；Watson 的 focus 与 LAT，Lally 等 2012）。（2026-10-25 原文核对：粗、细两级（6 个粗类、50 个细类，先粗后细）与 Moldovan 等的题目处理（定题型、答案类型、focus、关键词）有原文支持；“再按类别选择检索与抽取策略”只部分支持：Li & Roth 把按类型选策略写成动机，没有实现或评估；Moldovan 等用答案类型筛选候选答案，检索由关键词启发式决定。focus 的定义见上段补注；Lally 等只有 IEEE 付费版，未读、不使用。）
- 起作用的部分：题目的句式与疑问词决定要找的是什么证据。“是不是 / 有没有”要找被点名的物体本身，“是什么 / 在哪里 / 在做什么”要找与它相关的另一样东西。（2026-10-25 原文核对补注：这两篇只处理 wh 问句，没有是非题；按疑问词分题有原文支持，但两篇都说只看疑问词不够。“是不是 / 有没有要找被点名物体本身”是本项目自己的推断与数据（SQZ-EXP-0018 S8），VQA 中的先例是 GVQA。）
- **核对状态（2026-10-25 更新）**：Li & Roth、Moldovan 等已逐页核对原文（[领域 B 原文核对](论文笔记/domainB_原文核对_LiRoth_Moldovan.md)，PDF 在 papers/，sha256 6133941c…、5a35e1c1…）；Lally 等只有 IEEE 付费版，未读、不使用。原核对状态：问答系统三篇（Li & Roth、Moldovan 等、Lally 等）只到检索摘要级。迁移只用到“按句式分两类”这一最粗的形式，不依赖原文的分类器细节。
- **VQA 中的直接先例（C，子代理读过 ar5iv 全文）**：
  - GVQA（Agrawal 等，CVPR 2018，arXiv 1712.00377）用题目分类器把是非题与非是非题送进不同模块；
  - QTA（Shi 等，ECCV 2018，arXiv 1804.02088）用题型 embedding 给两路视觉特征加权，最优特征随题型变化。
  - 本方案把同一思路用在 token 选择上。

## 相近工作与新颖性（2026-10-25 检索，子代理，约 90 个来源，只读摘要页与 HTML，未读 PDF；`D:\6CJNM007\tmp\exp0020\lit_router.md`。同日补读 CLASP、VIP-Router 原文，见 PAPER-0008、PAPER-0009）

- **没有找到完全相同的做法**：零训练、按题目表层句式（是非句、how many）硬路由；一端是输入 embedding 余弦，另一端是注意力排序。
- **上位概念已有，不能声称“首次按题型剪枝”**：
  - **CLASP**（Dang 等，arXiv 2604.12767，2026-04，会议未知）：文本路由器把 prompt 分到 9 个意图类别（标签由 Qwen3-8B 加少量关键词规则得到），每类在校准集上搜出“指令注意力 token 与纯视觉多样性 token”的预算比例，以及 ViT 层融合权重。它在 LLM 第 {2, 6, 15} 层剪枝，评测含 LLaVA-1.5-7B、VQAv2、POPE。它报告计数类偏好高注意力比例。本方案可以看作它“两类、比例取 0 或 1”的特例。（2026-10-25 原文核对修正，PAPER-0008：①“特例”只在结构上成立。CLASP 的两个选择器是注意力 pivot 与特征空间多样性；我们的是题目查询与 A（注意力 + 空间分块）；题目查询的份额是 S，不是 1。②“计数类偏好高注意力比例”只在 MMVet（计数 5 题）上这样说；TextVQA 上计数类在 0.3 最好，MME 上在 0.9 最好，最终取 0.6。③原文补充：路由器是 Qwen3-8B（15.5 GB）；每类参数在带标准答案的校准集（每类 2,000 条）上离散搜索；LLaVA-1.5-7B 上报告 VQAv2 77.1 / 76.7 / 75.2、POPE 85.6 / 85.2 / 82.8（192 / 128 / 64）；有单独的计数类，没有存在类；不按答案类型报告效应。）
  - **VIP-Router**（Liang 等，arXiv 2609.10346）：学到的路由器为每个样本在 {Full, FastV, VisionZip, PruMerge+, DART} 中选一个。它没有 VQAv2 结果，也没有按题型的分析。（2026-10-25 原文核对，PAPER-0009：路由器约 138 万个可训练参数，建在冻结的 CLIP 特征上，用 VTC-Bench 中 Qwen2-VL-7B 的逐策略正确性标签训练；只在“全 token 答对、降采样答错”的 Group A 上评测；LLaVA-1.5-7B 只出现在跨模型的汇总表里；没有规则路由的对照；把逐样本 oracle 当作上界。）
  - **AdaFV / AdaV**（Han 等，arXiv 2501.09532；Findings ACL 2025）：按分数分布逐输入拆分“文本—图像 embedding 余弦”与“[CLS] 显著性”两部分预算，不看题型。
  - **PTP**（arXiv 2509.15704）把“按任务调节指令引导的权重”列为未来工作；**Wen 等**（Findings ACL 2025）认为文本引导只在任务与语言强相关时有益；**QMoP**（arXiv 2603.21232）用查询引导的路由器给三条压缩分支加权（需训练）。
- **仍可能成立的贡献（推断）**：
  - 路由变量是答案类型 / 表层句式，零训练、不加模型、可解释；
  - 机制证据：没有找到按 VQAv2 答案类型报告“题目引导选择对存在、计数有利、对问点名物体属性的开放题有害”的剪枝论文（F38、F39）；
  - 按题目词选 token 本身不新（CDPruner、AdaFV、FlashVLM 等用文本—图像相似度），IDF 加权均值作查询未见先例，但改动很小。
  - （2026-10-25 原文核对后的限定，PAPER-0008）路由轴的差异只在是非 / 存在题一侧：CLASP 也单独处理计数题。不需要校准集和额外模型是真实的差别，但我们的规则是看过 test1 后选的，要如实写。VQAv2 上 CLASP 报告的数字更好：按各自 vanilla 归一化，64 档 CLASP 95.9% 对我们 89.5%，128 档 97.8% 对 97.4%，192 档 98.3% 对 99.1%（划分不同，CLASP 很可能是 test-dev，我们是验证集子集；AI）。POPE 64 档持平（82.8 对 82.74），128、192 档我们低 0.2～0.5。不能写“优于 CLASP”。
- **表述修正**：
  - ①被点名的物体是题目的话题，不是问答术语里的 focus（focus 指答案所指的部分）；本项目文档已改。（2026-10-25 原文核对：这条以 Moldovan 等为出处不成立，见“要解决的问题”一节的补注；论文中不用 focus 一词。）
  - ②FastV 的末 token 注意力在文献中被视为受文本影响（Wen 等专门构造 FastV_VIS 去掉文本影响）。本项目测得它几乎不随题目变化（同一张图换题目，保留集合 Jaccard 0.945～0.957，F15、F28），论文中写成“几乎不随题目变化的注意力排序”，不写“与文本无关”。
- **论文需要的对照（推断）**：
  - 不路由的固定混合（即 A′+B+V）；
  - 逐题 oracle 上界（每题取两路中较好的一路，EXP-0020 计划 v1.1 加入报告）；
  - CLASP 式“两类 → 比例”在开发集上搜索，需要新的开发运行，作为后续。

## 对照与预测

| 组别 | 配置 | 作用 |
| --- | --- | --- |
| A | `fastv{64,128}_prior_strat_nopad_kl` | 强对照 + 排除填充区 |
| A′+B+V | `fastv{64,128}_qvis_kl` | 上一轮的方法（复验 F38） |
| 路由 | `fastv{64,128}_qroute_kl` | 本方案 |

- **预测**：
  - 64 档：路由 − A 为正。test1 的事后估计是 +1.15 [+0.51, +1.77]，规则是看过 test1 后选的，新数据上预计会小一些。
  - 128 档：接近 0，test1 上 +0.13。
  - A′+B+V − A：yes/no 为正、other 为负（F38 复验）。
- **成功**：64 档路由 − A 的区间在 0 以上，这样 POPE 与 VQAv2 两个 benchmark 在 64 档都显著提升，MME-P 不变（差异不显著）。128 档成立则跨预算。
- **停止 / 回退**：64 档不成立时，方法的适用范围限定为“答案依赖被点名物体本身的题目”（POPE、yes/no、计数），VQAv2 作为边界报告。是否继续找让开放式题目也受益的机制，回到第 ⑨ 步再决定（C18 的后半）。

## 风险

- 规则在 test1 上选出，只能在新数据（test2）上确认；test2 与 test1 同分布（同一图像池），不是新的 benchmark。
- 只对英文、VQA 式短问句有效；“Is it X or Y?” 这类选择题是 other 类，但会被路由（test1 上占 other 的 6%）。
- 方法简单。贡献在于说明“何时该按题目词选 token”，规则本身不是贡献；论文中如实写出，并与 CLASP、VIP-Router 区分。
- test1 上的逐题 oracle（每题取 A 与 A′+B+V 中较好者）是 +6.93（64 档）、+3.61（128 档），远大于路由的 +1.15、+0.13。两路答对的题很不相同，但只看题目文字能取回的只是一小部分；oracle 含“两次有噪声的选择取较好者”的乐观偏差（analyze_0020.py 的空跑）。test2 上（预注册）：oracle +6.90，路由 +1.22；任意两种方法的逐题 oracle 都有 +4.95～+9.07（SQZ-EXP-0020 S5），所以 oracle 不是可达的上界。
