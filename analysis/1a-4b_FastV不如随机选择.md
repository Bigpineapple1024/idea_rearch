# 1a–4b 机制分析：同一层平均预算下，FastV 为什么不如随机选择

状态：第 1 轮完成（2026-10-24），3a（EXP-0008）、3b（EXP-0010）都已运行。分析 ID：1A4B-0001 / 关联实验：EXP-0002、EXP-0006、EXP-0008、EXP-0010 / 关联现象：F8、F10、F11、F15（[已发现的实验现象](已发现的实验现象.md)）/ 矩阵：[MODE_C-0002](MODE_C-0002_视觉token剪枝.md) 的 C9。

| 2a 追问到模块/运算/算子 | 打分在 `fastv_llava.py` 第 K 层前：`attn.mean(dim=1)[0, -1, start:start+n_img]`，即第 K-1=1 层、prompt 最后一个 token 那一行 softmax 注意力在各 head 上的平均。最后一个 token 位于问题文字之后；图像 patch 按行优先排列，第 i 个 patch 与最后一个 token 的相对距离是“问题长度 + (575 − i)”，随 i 增大而单调减小。LlamaAttention 在点积前对 q、k 施加 RoPE 旋转（`apply_rotary_pos_emb`），RoPE 的远程衰减使相对距离越小的 token 点积期望越大。因此在内容信号很弱的第 1 层，分数主要随 i 增大，top-k 选出的就是图像底部（行号大）的 patch。第 0 行的小峰（E-SQZ6-2）可能是图像起点处的 attention sink | 打分代码：fastv_llava.py；RoPE：transformers 4.37 modeling_llama.py；分数随位置的曲线本身**没有**直接测量 | 3a：测“纯位置”的分数曲线 |

当前可靠认识：FastV 在 K=2 时的保留集合由位置主导、几乎不看问题，这是它在激进预算下不如随机的直接中间量。打分里有一条与内容无关的位置曲线，除掉它就补回大部分差距（EXP-0008）；但校正后仍只与随机持平，选择也仍不看问题。EXP-0010 进一步表明主要机制是空间集中：不动分数、只强制覆盖就追平随机，去位置 + 覆盖则超过随机（F24）。仍属推断的部分：位置偏差来自 RoPE 衰减；被删的正是题目物体。

新颖性（2026-10-24 检索，摘要级）：FEATHER（Endo 等，ICCV 2025，arXiv 2412.13180）已报告 FastV 式剪枝丢掉图像上部，并用“去掉底部偏置 + 均匀采样 + 两阶段剪枝”修正，还报告注意力打分在第 8 层之后比第 3 层更有效。因此“位置校正的注意力打分”不能作为本项目的新方法；本项目的结果（纯灰图上的位置曲线、配对区间、补回 88%）是独立复核。

新发现与下一轮追问：① 第 0 行的小峰是不是 attention sink？② 更深的 K 是否仍然不看问题？（FastV 论文认为浅层之后注意力已集中，但没有说明与问题的关系。）③ 按论文描述的“所有 token 的平均注意力”打分，位置偏差是否更轻？

停止、回退或推进依据：3a 若显示校正后覆盖与 yes 比例都恢复，则把“位置校正的注意力打分”作为第 ⑦ 步的候选方向之一（新颖性需先与 SparseVLM+ 的 RoPE 校正、DART 等比较）；若都不恢复，回到 2a 重新追问（例如第 1 层是否根本没有内容信号）。**3a 之后（2026-10-24）**：覆盖与 yes 比例部分恢复，但 FEATHER 已做过同类修正，所以这条线在第 ⑦ 步只作为“已知修正在本设置下的复核”，不作为新方向；EXP-0010 跑完后结束本轮。**3b 之后（2026-10-24）**：F8 的主要机制是空间集中，位置偏差是集中的原因之一；去位置 + 覆盖后 FastV-64 超过随机，但 POPE 上仍比 VisionZip-64 低 12.4。本轮结束；剩下的差距（层分布或题目相关的选择）进入第 ⑦ 步的候选（MODE_C-0002 的 C12、C14）。
