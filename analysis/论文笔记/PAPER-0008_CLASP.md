## 研究问题

不同类型的问题需要的视觉特征层级不同，对“相关性”和“覆盖面”的需求也不同。能否先按题目文字判断类别，再按类别调整 ViT 层融合和剪枝预算的分配？（p.2 §1；p.4 Fig.2）

## 方法与贡献

- **路由**：文本路由器把 prompt 映射到 9 类之一（Eq.7，p.4）。9 类为：物体识别、属性/品种、文字/符号、场景理解、空间关系、计数、动作/交互、意图/功能、默认（p.17 Table 6）。类别标签的来源：Qwen3-8B 按 15 个细类输出 JSON，加关键词规则（例如把 “who wrote” 归入文字类），再合并成 9 类（p.16 附录 A）。默认的在线路由器是 Qwen3-8B（p.31；p.33 Table 24）。
- **类自适应层融合**：每类一行层分数 w_c；softmax(τ·w_c) 得到层权重，对同一 token 的各层 ViT 特征做凸组合，再过原冻结 projector（Eq.8–10，p.4–5）。Table 6 直接给出系数，例如文字类 {L5:0.2, L22:0.8}，计数类 {L5:0.2, L15:0.3, L22:0.5}（p.17）。τ 的取值未见报告（UN）。Table 6 的层号从 0 还是 1 起算，未说明（UN）。线索互相矛盾：Eq.1 写 l = 1…L（p.3）；Fig.2 把 ViT 层标为 layer 0…23（p.4）；p.29 把 0 起的 [2, 17, 23] 换算成第 3、18、24 层，Table 20 用后者（p.32）。
- **类自适应双阶段剪枝**：每类一个比例 a_c，K1 = ⌊a_c·R⌋，K2 = R − K1（Eq.11，p.5）。
  - Stage I：按注意力分数取 top-K1 作 pivot（Eq.12，p.5）。
  - Stage II：对其余 token 算与 pivot 的最大余弦，取最小的 K2 个作初始中心；球面 K-means 迭代 T=5 次；每簇取 medoid（Eq.13–17，p.5；C.3，p.22–23）。
  - 余弦在 projector 输出的视觉 token 上算（p.5 的 u = z̃/‖z̃‖；p.28 的聚类次数消融）。
- **剪枝位置**：沿用 SparseVLM，在 LLM 第 2、6、15 层分三段剪；每段都做 Stage I + Stage II（p.4 §4 Overview；p.5 Algorithm 1）。
- **注意力的参考集 S**：正文写“指令 token 或指定的 summary/query token”（Eq.4，p.3），附录写“视觉 [CLS] 或选出的文本指令 token”（Eq.33，p.22）。解码层里实际用哪一种，未说明（UN）。
- **参数如何得到**：不微调 MLLM。在带 gold answer 和类别标签的校准集上，以下游指标为目标做离散子空间搜索（Eq.20–21，p.17；Algorithm 2，p.19）。校准集为每类 2,000 条的平衡集（p.16）。正文全部结果用这组搜索出的配置（p.16）。LLaVA 系列共用一组融合参数；a_c 在所有模型间相同（p.16）。
- **贡献（SC，p.2）**：指出固定 ViT 层、固定注意力/相似度比例的局限；提出类自适应层融合；提出类自适应双阶段剪枝；多基准验证。

## 结果及不确定性

- **LLaVA-1.5-7B 主表**（Table 1，p.7）：归一化平均 98.4% / 97.0% / 94.7%（192 / 128 / 64）。
  - VQAv2：77.1 / 76.7 / 75.2，vanilla 78.4。
  - POPE：85.6 / 85.2 / 82.8，vanilla 85.9。
  - MMB：61.3 / 60.7 / 59.1，三档都低于 VisionZip（64.5 / 63.4 / 60.1）。
- POPE 的指标：正文称 128 档的 85.2 是最好的 accuracy（p.6）；附录 A 说除非另有说明，报告的都是 accuracy，并介绍 POPE 有 Accuracy、Recall、Precision、F1 四个指标（p.12）。但表中 vanilla 85.9 与本项目实测 POPE F1 均值 85.90 相同，而本项目 vanilla 的准确率均值是 86.87（EXP-0002-R04），所以这一列很可能是三个子集 F1 的平均（AI，与原文字面说法相反）。
- **组件消融**（Table 10，p.25；R=192）：MME / TextVQA / GQA / POPE 分别为 Baseline 1721 / 56.1 / 57.6 / 83.6；+Fusion 1814 / 56.9 / 59.6 / 85.0；+Ratio 1787 / 56.6 / 58.4 / 84.7；两者 1848 / 57.6 / 60.4 / 85.6。Baseline 四个数与 Table 1 的 SparseVLM-192 完全相同（AI：Baseline 就是 SparseVLM 流程）。
- **静态融合对照**（Table 20，p.32）：固定层 [3, 18, 24] 的 MME 为 1756 / 1701 / 1614，CLASP 为 1848 / 1790 / 1709（192 / 128 / 64）。
- **其他模型**：NeXT-7B 320 档 95.2%（Table 2，p.8）；Qwen2.5-VL-7B 比 SparseVLM 高 2.4 / 3.6 / 6.1 个百分点（p.6–7 正文；Table 3，p.8）；LLaVA-1.5-13B 32 档 87.5% 对 80.3%（Table 11，p.25–26）。
- **效率**：POPE 上 R=192 端到端 1.5×，R=58 为 2.1×（Table 5，p.7–8）。R=192 端到端 Total Time 223.1ms（按量级应为单个样本，AI），其中 K-means 27.2ms、分类器 <2ms、层融合 <0.5ms（Table 23，p.31、p.33）。
- **路由稳健性**（Table 22，p.30–31、p.33）：强制 50% 样本进默认类，MME 1756、POPE 83.6；随机错分 100%，MME 1627、POPE 77.4。换路由模型（Llama3-8B、Qwen3-32B），MME 1840–1848，POPE 85.3–85.7（Table 24，p.31、p.33）。
- **不确定性**：主表无区间；对比数字来源未说明；有多处内部不一致（见「限制与替代解释」）。作者数据未独立复验。

## 关于计数、文字、存在类，原文说了什么

- **计数**：
  - 动机实验（MMVet，R=192）：层融合从混合移向深层时计数类变差，29.5 对 27.9（p.2；Fig.1 上，p.1；Table 15，p.28）。
  - 原文说计数类需要较高的注意力比例（0.7–0.9）（p.2）。Table 17 的 MMVet 计数列在 p=0.7 最高（30.5），p=0.9 为 29.6（p.30）。
  - Table 17 的其他基准并不一致：TextVQA 的计数类在 p=0.3 最好（57.48）（p.28；p.30）；MME 的计数类在 p=0.9 最好（1816）；SQA 的计数类几乎不变（68.22～68.32）（p.30）。
  - 解释：计数和 OCR 这类重细节的题受益于中浅层特征（§4.1，p.4；p.29）；Stage I 用来保护计数目标这类小区域（p.5）。
  - 最终配置：计数 a_c = 0.6，融合 {L5:0.2, L15:0.3, L22:0.5}；融合系数与物体识别类相同，但物体识别的 a_c 是 0.8（Table 6，p.17）。
  - 这组融合就是 Table 15 的策略 B（图例 0.2L5 + 0.3L15 + 0.5L22，p.28）。而 MMVet 上计数类在 B 下只有 27.8，是五种策略里最低的；最高的是 D（29.5）（Table 15，p.28；Fig.1，p.1）。最终配置为什么这样选，原文没有解释（AI）。
- **文字**：
  - 动机实验（MMVet）：文字类在比例约 0.3 时最好（p.2）。
  - 在 TextVQA、SQA、MME 上，文字类对层选择最敏感：策略 C 下 TextVQA 12.03、SQA 14.83，策略 B 下 MME 731（Table 15，p.27–28）。MMVet 上最敏感的是空间类（B 16.2、C 14.0，p.27–28）（读表，AI）。
  - Fig.5（p.34）的 MME 图把 731 放在 L12/L15/L19（即 C）一行、1433 放在 L5/L15/L22（即 B）一行，与 Table 15 相反；TextVQA、SQA 两图与表一致（按 PDF 文字坐标核对，图像未看）。哪个对，未知（UN）。
  - 最终配置：文字 a_c = 0.7，融合 {L5:0.2, L22:0.8}（Table 6，p.17）。与 MMVet 动机实验的 0.3 不一致，原文未解释（AI）。
  - 但 Table 17 中 TextVQA 的文字类随 p 增大而上升，p=0.9 最高（57.00，p=1.0 为 56.99）；MME 的文字类在 p=0.1 最高（1815）（p.30）。所以 0.7 与 TextVQA 的趋势并不矛盾（AI）。
- **存在（是否存在某物体）**：
  - 9 类里没有“存在”类（Table 6，p.17）。
  - POPE 的 8,910 题全部归入物体识别（2,277）和场景理解（6,633）（Table 7，p.17）。
  - 原文把 POPE 描述为物体幻觉的是非题（p.12）；对 POPE 只报告总分，128 档称“更忠实”（p.6）。没有按类分析 POPE。
- **样本量**：MMVet 计数类只有 5 题、文字类 12 题（Table 7，p.17）。p.13 介绍 MM-Vet 用 LLM（通常是 GPT-4）给开放式回答打分；本文用哪个评分模型没写（UN）。

## 限制与替代解释

- **校准依赖**：需要带 gold answer 的标注校准集和类别标签（p.17 B.1），每类 2,000 条（p.16）。校准集从哪里来、是否与评测集同源，原文未写（UN）。若取自同一 benchmark 的训练集，配置会贴合这些分布（AI）。
- **路由器成本**：默认路由器是 8B LLM，在线显存 15.5GB（Table 9，p.19；Table 24，p.33），p.18 却称它为 lightweight routing model。原文称在线分类 <2ms（p.18–19；Table 23，p.33）。15.5GB 与 8B 模型 fp16 权重的量级一致；在 A100 上即使只做一次前向，按约 2TB/s 的显存带宽读一遍权重也要约 8ms，<2ms 难以解释。是离线预先分类还是批量摊销，未说明（AI/UN）。JSON 输出只在 p.16 构建分类数据时提到，在线路由器输出什么格式，没写（UN）。
- **显存口径**：Table 5 的显存 17.6G（Table 23 为 17.62GB）若含 15.5GB 的路由器，留给 LLaVA-7B 的不到 3GB，不合理，所以很可能不含路由器（AI）。

### 哪些重叠是真的（AI）

1. 核心思路重叠：剪枝前只看题目文字分类，再按类别改变剪枝策略。CLASP 公开在先（arXiv 预印本，2026-04-14，p.1）。不能写“首次”。
2. 结构重叠：两边都在两个选择器之间按类别分配预算。CLASP 的 a_c 定义在 [0, 1] 内（Eq.20，p.17），实际值从离散网格中搜出（p.18–19）；我们的路由相当于在“题目查询占 S 份 + A”与“全部 A”之间二选一。
3. 设置重叠：同一模型（LLaVA-1.5-7B）、同样的 VQAv2 和 POPE 基准（VQAv2 划分不同）、可比的预算口径、第一段都在 LLM 第 2 层。审稿人很可能会拿 CLASP 来比。
4. 都用 projector 输出空间的余弦：CLASP 用于图像 token 之间的多样性，我们用于题目查询与图像 token 的相似度。用途不同，但“在输入 embedding 空间算余弦”本身不新。
5. 计数类重叠：CLASP 有单独的计数类（Class 5，p.17 Table 6），我们的路由也单独处理 how many 题。

### 哪些差异站得住（AI，附理由）

1. **路由轴不同**：我们按答案类型（是非 / 计数 对 其他）分，理由是有直接证据：同一选择在这两类题上效果相反（F38、F39、F42）。CLASP 按视觉能力分，POPE 的存在题被归入物体或场景类，它的分类不区分“答案是不是被点名的物体”。但 CLASP 也有计数类，所以差异只在是非 / 存在题一侧，不能说整个路由轴都不同。
2. **零校准、零额外模型**：不需要标注校准集、不需要 8B 路由器、不需要搜索。代价是规则在 test1 上选出，需如实写。
3. **“按题目”的信号不同**：CLASP 的相关性来自注意力；我们测得第 2 层的注意力几乎不随题目变化（CL-1），所以改在输入 embedding 空间建查询（CL-5：同样的 IDF 权重放在注意力上无效，放在 embedding 上 +17.74）。这条可以作为“为什么不用注意力”的论据，但 CLASP 的 S 不同于 FastV 末 token，不能说 CLASP 的注意力也不随题目变化。
4. **机制证据**：按 VQAv2 答案类型给出“何时该按题目词选 token”的证据，CLASP 没有。

### 站不住或需要限定的说法（AI）

1. “优于 CLASP”：POPE 64 档持平，128、192 档略低；VQAv2 64 档按 vanilla 归一化低约 6 个百分点。只能写“在不校准、不加模型的条件下接近 CLASP 的 POPE 结果”，并注明划分不同、CLASP 未复现。
2. IDEA-0003 中“本方案可以看作它‘两类、比例取 0 或 1’的特例”需要修正：CLASP 的两个选择器是“注意力 pivot / 特征多样性”，我们的是“题目查询 / A（注意力 + 空间分块）”，选择器不同；我们题目查询的份额是 S，不是 1。只能说结构上相似。
3. IDEA-0003 中“它报告计数类偏好高注意力比例”需要限定：原文只在 MMVet（5 题）上这样说（p.2）；Table 17 中 TextVQA 计数类在 0.3 最好，MME 在 0.9 最好（p.30）；最终比例是 0.6（p.17）。
