## 研究问题

按注意力取“高亮” token 的剪枝（LLM 里的文本—视觉注意力，或视觉编码器的 [CLS] 注意力），在剪得很多时只留下局部显著、彼此相似的 token，丢掉整图的上下文。怎样找到并保住那些注意力不高、但对整体理解必要的 token？（p.1 摘要；p.2 §1；p.4–5 §3）

## 方法与贡献

- **位置与输入**：在进入 LLM 之前剪（p.5 §4；p.6）。只用视觉信息：作者认为 LLM 的语言偏差会带来幻觉，所以用“以视觉为中心”的方案（p.3 §2.2）；选 token 时不用题目文字（DE）。全文没有任何训练或微调步骤，作者称即插即用（p.1）；“training-free”一词没有用来描述 HoloV 自身（DE）。
- **步骤**（公式内容未见，按 p.5–6 的文字整理；标 AI 的是按文字补全的推断）：
  1. **分块**：把 N_v 个视觉 token 均分成 C 块，每块 M 个（p.5–6）。块数 C = [1024/N]，N 为保留数，名额越少块越多（A.3，p.21）。LLaVA-1.5 的 576 个 token：64 个时 16 块、每块 36 个；128 个时 8 块、每块 72 个；192 个时 1024/192 ≈ 5.3，括号是哪种取整没写（UN；只有取 6 才能均分，每块 96 个，AI）。块是图上的二维方块还是序列上的连续段，文字没写清（摘要用 spatial crops；16 块可排成 4×4 个 6×6 的方块，8 块排不成正方形网格，AI；UN）。
  2. **块内相似度**：块内各 token 的归一化向量两两相乘得到相似度矩阵，用（1 − 单位阵）去掉自身（p.6）。用哪一层的向量没写（UN）；§3.1 把投影层的输出记为 z_v（p.4），这里用同一符号 Z_v，推断是投影层输出（AI）。
  3. **块内“多样性”**：每个 token 与块内其他 token 的相似度的方差 V；V 高表示它和其他 token 的联系多样（p.6）。“按行求方差”是 AI 的读法。
  4. **打分**：H = γ·V + A，A 是视觉 [CLS] 对该 token 的注意力（p.6；H 的写法见附录 C 条件 C2，p.25）。γ 称为“自适应缩放”，怎么算未见（UN）。[CLS] 注意力取视觉编码器哪一层、各头怎么合并，未见（UN）；p.4 §3.1 只说关注视觉 [CLS] 给各 token 的注意力。
  5. **块间分名额**：块的优先级 = 块内各 token 得分的平均；归一化成权重 w_c，τ 控制分配的尖锐程度（p.6；形式推断为带温度的 softmax，AI；τ 的取值未见，UN）。初始名额 q_c = ⌊w_c·N̂_v⌋（N̂_v 为保留总数），每块不超过 M 个；取整后的余额按 w_c ×（M − q_c）的比例补给还有空位的块，仍有余额就给权重最高的块（p.6）。
  6. **块内取前 k 个**：k = q_c，按一个“兼顾块内显著性与全局相关性”的分数取（p.6；分数式未见，UN；可能就是 H，AI）。只选不合并（DE）。
  7. 保留的 token 送入 LLM。顺序与位置编号未见（UN）。
  8. **快速视觉上下文回取（VCR）**：在 LLM 中间的某个“触发层”，模型不确定性高时，把被剪掉的 token 当作 FFN 的额外 key-value 记忆读一次；注入比例 α ∈ [0, 1]，作者说与图像复杂度成正比（p.6 §4.1.1；p.26 D.1–D.2）。触发层、不确定性怎么量、阈值、α 的取值都未见（UN）；各结果表是否开了 VCR，全文没有说，也没有 VCR 的消融（UN）。D.2 里出现 “MemVCR” 的写法和 “N_v = 256（ViT-L/14）” 的例子，与 LLaVA-1.5 的 576 个不符；作者自己的 [101]（同一组作者的“记忆空间视觉回溯”，ICML 2025，p.17）做的是同类的视觉回溯。这一节可能沿用了 [101] 的写法（AI）。
- **理论**（附录 C，p.25–26）：假设每个被剪 token 都有一个足够近的保留 token、且上下文方差有界（C1），保留 token 的 H ≥ γ（C2）；借 Transformer 层的 Lipschitz 连续性给出输出差的上界（定理 C.1）；称名额分配在贪心选择下有 1 − 1/e 的近似（推论 1）。[AI] C1 本身就是要证明的覆盖性质；正文的分配是按比例取整再块内取前 k，不是对某个子模函数做贪心，推论与方法对不上；C2 里 γ 同时当系数和阈值用。推论后的说明句用第二人称称呼“你的分配策略”（p.26），像未修改的草稿（AI）。checklist 第 3 题却答“没有假设和证明”（p.28–29）。
- **作者列出的贡献**：全文没有编号的贡献列表。按引言末段（p.3）与结论（p.10）归纳：
  1. 指出注意力优先的剪枝倾向留下语义相似的 token，剪得多时性能大降；原因是位置偏差和注意力分散（p.2；p.4 §3.2）。
  2. 提出 HoloV：用“方差调制的动态打分 + 有容量上限的分配”保住整图上下文（p.10）。
  3. 在多个任务、模型、剪枝率上超过已有方法，例如 LLaVA-1.5 剪掉 88.9% 后保留 95.8%（p.1）。
  4. 与模型无关、容易接入（p.3）。

## 预算口径

- **HoloV 的“保留 N 个”**：进入 LLM 的视觉 token 数。因为在 LLM 之前剪（p.5–6），LLM 每一层都只有 N 个，按本项目的口径层平均就是 N（AI）。唯一的例外是 VCR：若开启，中间触发层的 FFN 还会读一次被剪的 token（作为 key-value，不进注意力序列），“64 个”没有把它算进去（AI；是否开启 UN）。
- **CLS**：HoloV 用 [CLS] 注意力打分，但 [CLS] 本身是否送入 LLM，全文未见（UN）。LLaVA-1.5 训练时只用 576 个 patch（VisionZip 源码核验 E-VZ-C08），推断 HoloV 的 64 个都是 patch（AI）。
- **合并 token**：HoloV 只选不合并（p.6）。同表的 VisionZip-64 是 54 个主导 token（含 CLS）加 10 个合并的上下文 token（E-VZ-C12；VisionZip 补充材料 Table 6）；PruMerge、ToMe 也合并（p.20）。Table 1 不区分这几种“64 个”（DE）。
- **与 FastV 一族怎么对齐**：全文只说对照按原论文设置（p.21），没有给 FastV、SparseVLM、PDrop、DART、MustDrop 的剪枝层和每层个数（UN）。Table 1 中 FastV 三档、SparseVLM 三档和 VisionZip-64，在 7 个共有 benchmark（GQA、MMB、MME、POPE、SQA、VQAv2、TextVQA）上与 VisionZip 的 Table 1（PAPER-0006 解析全文 p.5）逐格相同（DE，逐格比对）；而 VisionZip 论文也没有给 FastV 的 K 与 R，也没说“64”是进入 LLM 的数、第 K 层之后的数还是层平均（E-VZ-C02）。所以 Table 1 里 FastV 的“64 个”按本项目的层平均口径是多少，无法确定（UN）。举例：若是“第 2 层之后留 64 个”，层平均约 96 个（(2×576 + 30×64)/32，AI）；本项目实测 SparseVLM 64 档每层为 576×3、82×4、32×9、18×16（SparseVLM 笔记所引 E-SV-C06、E-SV-C13），层平均约 82 个（AI 计算）。
- **对照版本**：Table 1 把 SparseVLM 标为 ICML25，但三档数字与 VisionZip 表中的 SparseVLM（2024.10）相同（如 64 档 POPE 75.1），与 ICML 版（arXiv v4）的 POPE 77.5 不同（SparseVLM 笔记）（DE；“版本标错”是 AI 的判断）。Table 1 的 VisionZip 192、128 档与 VisionZip 原表不同：192 档 MMB 64.5 对 63.0、MME 1767 对 1782.6、POPE 86.4 对 85.3；128 档 MMB 63.4 对 62.0、MME 1768 对 1761.7、POPE 84.7 对 83.2、SQA 68.8 对 68.9（DE）。来源未见（UN）。本项目实测 VisionZip 的 POPE F1 为 85.49 / 83.12 / 77.03（E-VZ-C14），与原表一致。不剪的 VQAv2，HoloV 写 78.4，VisionZip 写 78.5（DE）。
- **FLOPs**：§4.3 只算视觉 token 的每层 FLOPs（an²d + bnd² + cndm），称 n 大时二次项主导，减少比例约 2R − R²，略好于线性（p.7）。[AI] 对 LLaVA-1.5，n = 576 远小于隐层 d = 4096、FFN 中间层 m = 11008（p.26 也写 LLaMA-7B 的 D = 11008）。按注意力 4n²d、四个投影 8nd²、SwiGLU 6ndm 的常见算法，二次项只占每层视觉 FLOPs 的约 2%；剪掉 88.9% 时每层约减少 89%，不是 2R − R² 给出的约 99%。
- **时延**：Table 4 在 POPE 上测总时间、prefill、端到端延迟、显存和相对准确率（LLaVA-1.5-7B；硬件按 A.3 为 A800；batch 大小未见，UN）（p.9）。Fig. 14 在 LLaVA-NeXT-7B、剪掉 95%、GQA、输出长度 1 下测平均 FLOPs、显存和吞吐（p.27）。

### 动机实验（§3，p.2–5）

- **位置偏差**：FastV 的注意力偏向视觉序列的首尾；在 VQAv2 的样本上，同一层的注意力分布在样本之间高度相似，不同层之间形状略有变化，但高注意力 token 的集合保持稳定（p.4 §3.2、Fig. 4 右）。只有图示和文字，没有数字（SC）。
- **注意力分散**：[CLS] 注意力比文本—视觉注意力集中；后者前 20% 的 token 只占约 40% 的注意力（p.4、Fig. 5）（SC）。
- **随机保留**：随机掩码在 5 个 benchmark（MMBench、MME、MM-Vet、TextVQA、POPE）中过半胜过 FastV，在 TextVQA 上失败（p.5 §3.3、Fig. 6 上）（SC）。剪枝率和模型未见；图中的数配不上柱子（UN）。

## 限制与替代解释

- **对照数字多为引用，口径混在一起**：FastV、SparseVLM、VisionZip-64 的数字与 VisionZip 的表逐格相同，SparseVLM 的版本标注与数字不符，VisionZip 192、128 档的来源不明（E-HV-9）。“保留 64 个”一行里，有在 LLM 之前剪的（HoloV、VisionZip），有在 LLM 内第 K 层之后剪的（FastV 等），有合并的（VisionZip、PruMerge、ToMe），全文没有统一口径（E-HV-10）。[AI] 所以 Table 1 里的胜负不全是“同预算”的胜负。
- **平均值有多处与行内数字不符，都对 HoloV 有利**：E-HV-8、E-HV-14～16，以及 p.8 的“第二名 76”。[AI] 引用这些平均值之前要对照 PDF。
- **没有组件消融**：只消融了块数（E-HV-3）。V 项、按块自适应分名额（对比等额分块）、VCR 各贡献多少，全文未见；最直接的对照 FasterVLM（只有 [CLS] 注意力）不在 Table 1（E-HV-24）。[AI] 无法判断增益来自“空间分散”还是“方差项”。
- **VCR 是否开启不清楚**（E-HV-4）。若开启，“64 个”低估了模型实际读到的视觉信息，与只在 LLM 之前剪的方法不同口径（AI）。
- **两张表之间不一致**：Table 4 的 58 个比 Table 1 的 64 个还高（E-HV-13）。
- **MMBench 分类表噪声大**（E-HV-17）。
- **第三方数字更低**：FSR 的表中 HoloV-64 与 VisionZip-64 持平，POPE、MMB 比 HoloV 自报低 3.5、3.3，低于 DivPrune-64（E-HV-25）。FSR 的口径未核对（UN）。
- **动机证据是定性的**（E-HV-18～20）：位置偏差、随机胜过 FastV 都没有数字。
- **理论与 FLOPs 的说法**（E-HV-11、E-HV-23）。
- **填充区**：LLaVA-1.5 把图补成方形；本项目 F63 测得 [CLS] 注意力最高的 53 个 patch 里，平均约 4 个整块落在填充里。HoloV 的 A 项正是 [CLS] 注意力，全文没讨论填充区（UN）。[AI] 均匀的填充块内相似度方差小，V 项可能压低它们；但块平均分也可能因 A 偏高而多拿名额；未检验。
- **统计**：无误差条（E-HV-22），对最强对照的差值多在 1 分以内（AI）。
- **模型范围**：Qwen2.5-VL 只比 FastV；LLaVA-1.5 只有 7B（DE）。
- **超参数缺失**：γ、τ、VCR 的参数都没给，checklist 却称实现细节齐全（p.29–30）；复现要靠代码（AI）。
- **作者自述局限**（E-HV-21）：固定分块可能在复杂场景里漏掉细粒度语义；剪得多时仍下降 4.2%；未来做自适应分块、稀疏注意力、3D 数据、与幻觉缓解结合、边缘设备能耗（p.27）。影响声明另说按块分配可能在数据不够多样时加重别的偏差（p.27）。

### 重叠（AI）

1. **用空间覆盖修正注意力挤在局部**：HoloV 的按块分名额与 A 的分块轮流取解决的是同一个问题。本项目已把 FEATHER 列为 A 的先例（F24 的备注）；HoloV（p.6）和它在 A.2 里描述的 HiRED（按 CLS 注意力给各分区分预算，p.20）是另外两个先例。A 只能写成强对照，不能写成本文提出。
2. **位置偏差与“注意力几乎不随题目变”**：HoloV p.4 说 FastV 偏向序列首尾，在 VQAv2 样本上同一层的注意力分布在样本之间高度相似，与 CL-1 是同一现象。HoloV 只有图示，没有“同图换题”的设计和数字；CL-1 的先例除 FEATHER 外要加上 HoloV，写成“定量复核”。
3. **随机胜过 FastV**：HoloV Fig. 6 上（p.5）与本项目的 [1a-4b_FastV不如随机选择](../1a-4b_FastV不如随机选择.md)、F24 同向；HoloV 没给剪枝率和数字。
4. **在 CLS 打分的底座上再调空间分布，VQAv2、GQA 上收益都很小**：HoloV 自报相对 VisionZip-64 +0.4 / +0.2（Table 1）；本项目在 VisionZip-64 上按题目定位的覆盖 16，两组确认集合并后 +0.83 / +0.38（F71，事后合并），不看题目、只往居中框集中的对照在开发集上 −0.06 / +0.13（F57）。调法不同（HoloV 是按块分散，本项目是往框里集中），只能说方向一致。
5. **CLS 注意力不如多样性**：FSR 表中 HoloV-64 与 VisionZip-64 持平、低于 DivPrune-64（E-HV-25）；本项目 K = 1 时多样性选择比 CLS 排序高约 2 分（F72～F74）。设置不同（在 LLM 之前对 K = 1），方向一致。
6. 都免训练。

### 不重叠与新颖性判断（AI）

- **题型路由（IDEA-0003）**：HoloV 不看题目，没有按题型切换策略，也没有 VQAv2 答案类型的分析。不构成新颖性威胁。HoloV 不用题目的理由是避免语言偏差带来的幻觉（p.3），但没有做“看题目”的对照；本项目的证据（被路由的 yes/no、计数题受益，其余题受损）说明这件事要分题型，可以在讨论里回应。
- **K = 1**：HoloV 在 LLM 之前剪，没有比较剪枝层，也没有“第 0 层看全部”的设置，不构成威胁。VCR 让 LLM 在中间层读一次被剪 token，与“第 0 层全看”都是让模型接触被剪的内容，但位置和方式不同，且没有细节和消融；相关工作里并列一句即可，不必当对照。
- **覆盖 16**：HoloV 的名额分配不看题目；“把名额挪进题目查询定位的框”HoloV 没有做，不构成威胁。但“按块分名额保覆盖”这一半不新（HoloV、HiRED）。
- **已失败的方向**：
  - 预算内放大（IDEA-0004）：HoloV 没有做裁剪后重新编码。只有 Fig. 6 下的定性观察（只用局部块在 TextVQA、POPE 上好，只用整图在 MMBench 等上好，p.5），数字读不清，也不是同预算的比较，不能当 IDEA-0004 的旁证或反证。
  - 定位后覆盖在 VisionZip 上（IDEA-0006）：见「重叠」第 4 条。HoloV 的结果与“在 CLS 打分的底座上调空间分布收益小”一致，没有提供能让它成立的新线索。
  - 一层全看 + 按编码器排序（IDEA-0007）：HoloV 的打分主体也是 [CLS] 注意力。若把它的打分加按块分名额搬到 K = 1，按 F70（K = 1 时换一种排序，留下的 47 个只有约三分之一相同，准确率却没有可检出的差别）预计作用也小（未检验）。
- **DivPrune 底座**：HoloV 没有引用 DivPrune。只在 DivPrune 上加本项目的路由与覆盖 16，HoloV 不构成威胁；若下一轮做“DivPrune + 空间名额”或“DivPrune + 注意力项”，HoloV（[CLS] 注意力 + 方差 + 按块分名额）是最近的先例，必须引用并说明差别（多样性的定义、是否看题目）。
- **总体**：HoloV 没有做本项目想做的事（按题型、按题目定位、K = 1）。它与本项目重叠的是 A 的部件和几条诊断现象，这些本来就只写成对照和复核。

## 交接 Deep Read

- 候选 P：注意力优先的选择在低预算下挤在局部（位置偏差、空间集中）；不看题目时，名额怎样在空间上分配才能保住整图上下文？HoloV 的按块分配没有和等额分块、多样性选择分开比较（E-HV-3、E-HV-24）。
