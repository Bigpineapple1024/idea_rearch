# 时序预测三篇论文对比：DUET、TQNet、WPMixer

状态：partial，2026-10-23。材料：PAPER-0001～0003（代码已核验，论文全文未读）与 [EXP-0003](../实验报告/EXP-0003_record.md)（CPU 上真实数据复现，仅 ETTh1）。三篇论文由用户提供，并附推荐意见“DUET 优先考虑作为主 baseline”；2026-10-23 按[研究流程 v2.0](../研究流程.md) 的第 ① 步（近两年高引用、有源码、衍生工作多）和第 ② 步（复现门槛）定下 baseline（DEC-0009）。

## 用户提供的候选

| 论文 | 发表 | 用户的推荐理由 | 官方源码 / 许可证（已核实） |
| --- | --- | --- | --- |
| DUET | KDD 2025 | 优先考虑作为主 baseline；时间与变量双重聚类，训练和统一评价脚本较完整 | decisionintelligence/DUET，MIT ✓ |
| TQNet | ICML 2025 | 结构轻量，周期先验与注意力模块清楚，便于阅读和消融 | ACAT-SCUT/TQNet，Apache-2.0 ✓ |

用户对三篇的描述与代码一致。需要补充的是评测协议和可复现性方面的发现，见下文。

## 共性

1. 任务与设置相同：多变量长期预测，回看窗口 96 的统一设置，预测长度 96/192/336/720，指标 MSE/MAE，都在 ETT、Weather、Electricity、Traffic 等数据集上评测。
2. 都用实例归一化（RevIN 或等价操作）处理非平稳性。
3. 都依赖人为给定的结构先验：TQNet 的周期长度、WPMixer 的小波类型与分解层数、DUET 的专家数与 top-k。
4. 都只用单个种子报告结果；在 ETTh1 上，种子波动与方法间差距处于同一量级（E-TQ-08）。

## 差异

| 维度 | DUET | TQNet | WPMixer |
| --- | --- | --- | --- |
| 变量（通道）建模 | 频域可学习距离 → 采样稀疏 mask → 通道间注意力 | 周期移位的可学习 query 对通道做一层注意力 | 无跨通道混合（通道独立，权重共享） |
| 时间建模 | 按窗口路由到若干 DLinear 式线性专家（混合专家） | 线性投影 + 两层 MLP | 小波多分辨率分解，每个分辨率一个 patch + MLP Mixer |
| 需要的先验 | 专家数、k | 周期长度 cycle | 小波类型、分解层数 |
| 推理是否确定 | **否**：测试时通道 mask 也随机采样 | 是 | 是 |
| 测试集计分 | 所有窗口（TFB rolling） | 所有窗口 | **丢弃末尾不满一个 batch 的窗口** |
| 超参数选择 | 每个数据集、每个预测长度单独配置；主结果在多个回看窗口中报告最好结果（依据未知），另有回看 96 的统一结果 | 每个数据集一套，回看固定 96 | **Optuna 以测试集损失为目标调参** |
| 划分与归一化 | TFB：0.6/0.2/0.2（ETTh1 等同 12/4/4 个月），训练段拟合 scaler，指标在标准化尺度上算 | TSLib 标准 12/4/4 | TSLib 标准 12/4/4 |
| 规模与速度（ETTh1-96，CPU） | 366 万参数；每个 epoch 约 1 分钟，最多 100 个 epoch | 一次完整训练约 1 分钟 | 每个 epoch 约 52 秒（96 档），分解层数为 3 时更慢 |
| 依赖 | 重（TFB：ray、darts、merlion、dash 等） | 轻（numpy、pandas、sklearn、torch） | 中（optuna、PyWavelets、thop） |

## baseline 选择（DEC-0009）

| 用途 | 选择 | 依据 |
| --- | --- | --- |
| **主 baseline** | **DUET** | ①引用：Paper Digest 2025-09 版 KDD 最具影响力论文排名第一（该榜按引用统计，具体引用数待实查）；②有源码（MIT）；③基于 TFB 框架，框架内已有 20 多个对比方法，便于统一评测和组合实验；④**复现门槛已通过**：ETTh1-96 两个种子 0.3898、0.3790，报告值 0.377 落在种子波动范围内（还需在 GPU 上补到 3 个种子并覆盖更多数据集） |
| 对照 + 组合实验素材 | TQNet | 复现最精确、协议干净、训练快，适合做多种子和快速诊断；周期 query 可作为组合实验的素材 |
| 对照 + 组合实验素材 | WPMixer | 多尺度（小波）结构；进入对比表前必须在统一协议下重跑（全部窗口计分、只用验证集选超参数、多种子） |

旧版建议以 TQNet 为主 baseline，依据的是自设的“可信度优先”评分表，与方法论不符，已改正。保留下来的注意事项：

- DUET 种子波动较大（ETTh1-96 两个种子相差 0.011），按[执行规范](../研究流程.md)默认 3 个种子，下结论用 5 个。
- DUET 每次训练在 CPU 上约 11 分钟，在 GPU 上会快很多，但仍比 TQNet 慢。需要快速诊断时，可以先在 TQNet 上试，再回到 DUET 上确认。

## 复现中已发现的现象（待登记台账、待 squeeze）

以下来自 EXP-0003，尚未经过 squeeze-experiment 和 deep-read，只是候选，不是 idea：

| 现象 | 证据 | 备注 |
| --- | --- | --- |
| WPMixer 测试集 drop_last 使 MSE 偏低 0.003～0.009，预测越长越明显 | EXP-0003 R8、R10、R11 | 评测协议类发现；统一协议重评可作为论文的分析章节 |
| DUET 测试时通道 mask 随机，但只重采样 mask 时 MSE 标准差仅 0.0003 | EXP-0003 R12 | 影响很小，不值得作为改进方向 |
| DUET 两个种子相差 0.011，大于 TQNet 四个种子的极差 0.0068 | EXP-0003 R12、R14、R1–R7 | 需要更多种子确认；可能和混合专家路由的初始化有关（推断） |
| DUET 路由器用未做实例归一化的输入 | E-DU-04 | 先查论文是否有意为之 |
| TQNet 需要人为指定周期长度 | E-TQ-04 | 诊断：改变 cycle 看 MSE 变化 |

## 组合实验候选（研究流程第 ④ 步“制造意外实验”）

目的是产生意外现象，不要求先做新颖性检索；都以 DUET 为 baseline，先跑单独的 A、B，再跑组合。

| 候选 | 组合内容 | 想观察什么 |
| --- | --- | --- |
| DUET + TQ | 把 TQNet 的周期 query 用于 DUET 的通道注意力 | 全局周期先验和 DUET 的稀疏通道 mask 会不会冲突或互补 |
| DUET + 小波分解 | 在 DUET 的时间聚类前加 WPMixer 的多分辨率分解，每个分辨率单独路由 | 不同时间尺度是否被路由到不同专家 |
| DUET 去掉通道 mask 采样 | 用期望或阈值代替 Gumbel 采样 | 已诊断影响很小，排在最后 |

交叉结论：三篇的差异主要在“如何建模通道关系”和“如何建模多尺度时间模式”；而它们之间最大的、已被本项目实测确认的差异，是**评测协议**。在协议统一之前，三篇论文表格中的数字不能直接互相比较。
