交叉结论（证据范围：三篇论文代码 + LLaVA 代码）：

- 三篇论文分别改在 B1（VisionZip）、B4 的单一层（FastV）、B4 的多层（SparseVLM），免训练设置下都没有改 B2 投影层。VisionZip 明确讨论了 token 数骤减后视觉输入与 LLM 不对齐，并提供 VisionZip‡：冻结其余部分，只用 1/10 的 LLaVA-1.5 指令数据微调投影层（7B 在 8×A800 上约 30 分钟），64 档从 94.0% 提到 95.2%；FastV、SparseVLM 没有讨论这一问题。合并幅值、CLS、位置编号这三个具体来源，三篇都没有讨论（2026-10-24 已回查论文，见 PAPER-0006 源码核验 E-VZ-C13）。
- 位置编码（B3/B4 的 RoPE）是三者处理差异最大、却最少被单独检验的环节：FastV 和 SparseVLM+ 保留原始位置，SparseVLM v1 和 VisionZip 压缩位置。
- 高频改造不代表没有创新空间，未被改造也不证明不存在问题。以上为代码层面的观察，需要在真实权重上验证。

**目前最容易突破的现象**：B4-a 的位置偏差（F15 → F8）。理由：在本项目的 baseline 上造成了可测的大损失；机制链已追到 RoPE 与第 1 层注意力（还差“纯位置曲线”这一条边）；已有相近设置中的同方向修正（SparseVLM+ 的 RoPE 校正）。不确定的是新颖性，需要在第 ⑦ 步前补读 SparseVLM+、DART 等处理位置偏差的工作。

**更新（2026-10-24，EXP-0008）**：“纯位置曲线”这条边已测到（F16）。除掉位置曲线后，FastV-64 的 POPE 从 36.2 升到 57.4，补回与随机差距的 88%，但仍比随机低 2.85，比 VisionZip-64 低 19.6（F17）。所以 B4-a 的位置偏差是真实、可修的问题，但修好它只能让 FastV 回到随机的水平；要超过随机，还需要别的东西（更好的覆盖，或打分中真正与问题相关的信号）。EXP-0010 检查“去位置 + 强制覆盖”。新颖性：FEATHER（ICCV 2025，arXiv 2412.13180）已报告同一位置偏差，并用“去掉底部偏置 + 均匀采样 + 两阶段剪枝”修正（检索摘要级），所以 B4-a 在第 ⑦ 步不再是新方向的首选，本项目的结果算独立复核。

**更新（2026-10-24，EXP-0007）**：B4-b 与 B4-a 的混杂已拆开，结论见下：

- **SparseVLM 的优势来自规则（F19）。** 在 SparseVLM-64 实测的分布下换成随机选择，POPE 低 15.5、MME-P 低约 100。多出的漏答 93% 落在 vanilla 本来答对的正样本上。
- **FastV 的打分在两种分布下都不如随机，差距随分布变化（F21）。** SVP 下差 7.2，平坦下差 14.3。
- **前多后少的分布没有收益（F20）。** 层平均相同时，随机选择下 SVP 比平坦低 5.6；FastV 下 POPE 高 1.5、MME 低 87，方向不一致。这与 PyramidDrop 的金字塔直觉相反，与 HiDrop“浅层被动、融合从中层开始”的出发点方向一致（两篇都是检索摘要级）。

因此第 ⑦ 步中：

- B4-b 不再单独作为方向。
- B4-a 中值得看的是“与问题相关的打分”：SparseVLM 的文本评分者用题目文字打分，而 POPE 的题目直接写出物体名。这是推断，需要把评分者与回收分开（P-SQZ7-1）。

**更新（2026-10-24，EXP-0010 与 MME 的 yes 比例）**：

- **B4-a 的主要机制是空间集中（F24）。** 不动分数、只把排序分到 6×6 块里轮流取，FastV-64 的 POPE 就从 36.2 升到 61.5，追平随机；再去掉位置项升到 64.7，比随机高 4.4。这与 FEATHER 的两个部件一致，已知修正在本设置下有效，所以 B4-a 的“去位置 + 覆盖”只作为强对照。
- **剩下的 POPE 差距（比 VisionZip-64 低 12.4）有两个候选来源。** 一是层分布：FastV 把层平均 64 中的 36 个花在前 2 层，深层只剩 30 个，而 F20 显示深层数量仍重要；二是选择仍与问题无关（Jaccard 0.945）。
- **B4-d（解码行为）有了新的直接证据（F23）。** 剪枝后答案偏向哪边取决于问题类型：“有没有”类偏 no，身份识别类偏 yes。这一位置没有论文处理过，但现象已在两个 benchmark 上测到，按第 ⑥ 步的解读规则不属于“无解”的地方。

**更新（2026-10-25，EXP-0011～EXP-0021）**：（2026-10-25 跑偏检查补注）按骨架位置记下第 ⑧～⑫ 步中新增的已知内容，数字抄自现象台账、各实验记录、审计记录及其输出；FastV 一族（含本方法）都只在 LLaVA-1.5-7B、K=2、贪心解码下测过（DEC-0030）。A 指强对照（去位置 + 覆盖）再排除填充区；A′+B+V 指 IDF × 可视性加权的题目查询，名额按可见占比分给查询与 A 的分数；路由按题目句式在 A′+B+V 与 A 之间选。POPE 的配对区间按图像重抽（DEC-0030）。

- **B4-a：打分所在的前几层，注意力几乎不随题目变化（F15、F28）。** 第 1 层上，题目句均值行、物体名均值行、最后一个 token 行的同图不同题 top-30 Jaccard 为 0.980 / 0.931 / 0.959（开发集），物体上的注意力质量 ÷ 物体占 patch 比例为 0.95～1.00（不偏向物体）；第 0、2 层也一样。题目相关的注意力在第 8～16 层最强（只在开发集上测），K≤2 的同一预算下用不上（EXP-0011）。解释（推断，M12）：前两层的注意力权重由图像 token 一侧的显著性与位置决定。
- **B4-a 的位置偏差：64 档上，分块 + 排除填充区之后，位置先验已无可检出的作用。** POPE 上 A₀（A 去掉位置先验）− A 为 −0.85 [−2.57, +0.83]（EXP-0019；EXP-0008 中它的作用是在不分块时测的）。强对照的保留 token 有 18.0% 落在填充区，排除后 F1 只高 2.24（F26，EXP-0011）。位置曲线来自 RoPE 衰减还是 attention sink（P-SQZ6-1）仍未区分。
- **B2 的输出与 B4-a：在输入 embedding 上，图像 token 与题目词的余弦能找回被问的物体（F29、F34）。** 用物体名的余弦选（分块、排除填充区）：开发集上面积 ≤ 1.35% 的小物体命中 70.4%（强对照 35.4%），同图不同题 Jaccard 0.048；POPE F1 83.63，比强对照高 18.97，比 VisionZip-64 高 6.61（EXP-0011）。不知道物体名的位置时，用 IDF 加权全部题目 token 作查询（A′+B），结果相同（83.59，差 −0.04 [−0.33, +0.23]，EXP-0014）；限定：IDF 在被评测的题目文件上计（不用标签），POPE 只有一种句式（AU-10）。**“适配是必要的”得到支持**：IDF 权重用在第 1 层注意力行上，与只差一处的 A₀ 无可检出差别（+0.56 [−0.70, +1.96]）；用在输入 embedding 的查询上，比等权查询（A′）高 17.74 [15.82, 19.79]（EXP-0019，DEC-0032）。解释（推断，M11）：LLaVA 的投影把图像 token 放到与词 embedding 可比的空间。
- **B4-a 的最终方法：POPE 上的提升随预算缩小，MME-P 差异都不显著（F36、F37）。** A′+B+V − A：POPE 64 / 128 / 192 档 +15.84、+5.21、+2.29（[13.88, 17.82]、[3.94, 6.47]、[1.38, 3.22]），MME-P +50.4、−6.6、−20.6，区间都含 0（EXP-0015～EXP-0017）。名额一部分留给 A 后，MME 四个名字类子任务合计的损失从只用 IDF 查询时的 −82.4 缩小到 −23.7（F35、F36，审计修正，DEC-0030）；在切分之外，可视性没有可检出的贡献（EXP-0016）。POPE 上不改层分布（K=2、保留 30 个），只改选择规则，就从比 VisionZip-64 低 12.4（F24）变为高 5.72 [4.02, 7.42]。
- **B4-a 在一般题目上：效应按答案类型相反（F38、F39）。** VQAv2 test1 的 64 档，A′+B+V − A：yes/no +1.70 [+0.24, +3.12]，other −3.43 [−4.90, −1.94]，全部 −0.74 [−1.70, +0.20]（EXP-0018）；test2 上预注册复现（yes/no +1.65，other −4.03，EXP-0020）。损失集中在点名图中物体、问它的属性或关系的 other 题（−5.14 [−7.41, −2.96]），查询选的 token 多数落在物体框内时损失更大（−6.71 对 −3.59，事后探索）。解释（AI，M16）：题目点名的物体是话题，不一定是答案所在；被换掉的第 2 层注意力最高的 token 几乎不随题目变化（F15），可能带着开放式题需要的整体内容。
- **B4-a 的路由：按题目句式选规则（F42）。** 助动词或 “how many” 开头的题用 A′+B+V，其余用 A；POPE、MME-P 的题目全部被路由，在那里路由就是 A′+B+V。VQAv2 test2（预注册）上路由 − A：64 档 +1.22 [+0.58, +1.82]，128 档 +0.72 [+0.29, +1.15]（EXP-0020），192 档 +0.42 [+0.01, +0.82]（EXP-0021，只作描述）。64 档的增益来自 yes/no 与 number，每题耗时 +0.7%；不路由的题与 A 逐题相同。第 ⑫ 步的计划目标据此在 64 档达到（DEC-0033）。
- **B4-d：题目相关的选择不再偏 no，但误报比不剪枝多，区分力仍低（F30、F31、F41）。** 与题目无关的选择下，答 yes 的比例随被问物体上保留的 patch 数上升（POPE，0、1、2～3、≥ 4 个：10.8%、50.0%、67.6%、74.3%，F25 在 EXP-0011 复验）；题目相关的选择在 0 个时仍有 40.6% 答 yes（F30）。开发集 coco_dev3 上，物体名变体用 margin（log P(Yes) − log P(No)）区分正负样本的 AUC 比 vanilla 低 0.014～0.020，区间都在 0 以下：选择本身丢了区分信息，不只是阈值偏移；同预算的三类修正（混合名额、对比打分、校准）都没有显著提高 F1（F31～F33，EXP-0013）。最终方法 A′+B+V-64 的 yes 比例 40.4%～44.3%（A 26.0%～27.3%，vanilla 41.9%～44.0%），AUC 介于 A 与 vanilla 之间（比 vanilla 低 0.018～0.034），误报比 vanilla 多 26%～57%（F41，EXP-0019）；VQAv2 test2 的 yes/no 题上同样偏 yes（答 yes 的比例 A-64 0.436，路由-64 0.502，vanilla 0.471）。
- **B1 与 B4（在哪里选）：一般题目上，FastV 一族（含本方法）在 64 档低于 VisionZip，128 档无可检出差别（F40、F43，EXP-0021）。** VQAv2 test2 的 64 档：路由-64 − VisionZip-64 −2.17 [−3.22, −1.25]，几乎全在交给 A 的 other 题（对总差贡献 −2.13），A-64 在 other 上比 VisionZip-64 低 4.21；差距大的题型有 what does the（61 题中 36 题问标志或文字写了什么）、what color is the（EXP-0020）。128 档：路由-128 − VisionZip-128 +0.48 [−0.31, +1.19]，A-128 − VisionZip-128 −0.24 [−1.04, +0.52]（EXP-0021）。POPE 上相反（见上）。解释（AI，M17）：VisionZip 在视觉编码器里按 CLS 注意力选 token、把其余合并成 contextual token，保留了开放式题需要的整体内容；替代解释：第 2 层注意力选择本身丢掉了读字与属性所需的细节。仍未知：为什么只在保留 30 个时差距特别大（EXP-0021）；层分布（B4-b）与选择规则各占多少，没有实验拆开过（P-SQZ10-1 未做）。
- **没有涉及的位置**：B2 投影层本身（是否微调）、B3 位置编号、B5 KV cache，这些实验都没有改动或单独测试。B4-c 注意力实现只在诊断运行 EXP-0011-R04 中由 sdpa 换成 eager（为了输出注意力），只作核对：第 1 层最后一个 token 行与 sdpa 的运行相比，最大相对差 0.0016（EXP-0011）；vanilla 在两种实现下的答案在开发集前 1800 题上 100% 相同（EXP-0013）。
