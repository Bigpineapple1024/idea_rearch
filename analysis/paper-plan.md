# Paper Plan：实验到论文的宏观规划

状态：2026-10-23 更新（DEC-0009）。两条方向并行，各自处于第 ② 步“复现 baseline”。流程规范见 [研究流程 v2.0](研究流程.md)。下表不代表已经完成研究。

## 项目定义

| 项目 | 视觉 token 剪枝（T1） | 时序预测 |
| --- | --- | --- |
| 研究领域与核心问题 | 多模态大模型推理加速：免训练视觉 token 剪枝；候选问题见 [MODE_C-0001](MODE_C-0001_视觉token剪枝.md) | 多变量长期时序预测；候选现象见 [时序三篇对比](专题分析/时序预测_DUET_TQNet_WPMixer对比.md) |
| 主 baseline 与依据 | FastV（近两年高引用、有源码、衍生工作最多）；骨架模型 LLaVA-1.5-7B | DUET（KDD 2025 影响力榜第一、有源码、TFB 框架）；ETTh1-96 复现门槛初步通过 |
| 对照与组合实验素材 | VisionZip、SparseVLM | TQNet、WPMixer |
| 数据 | POPE（COCO val2014）、MME 为主；GQA、TextVQA 用于独立验证 | ETTh1/ETTh2/ETTm1/ETTm2、Weather、Electricity、Traffic（TFB 预处理版） |
| 主指标 | POPE 准确率、MME 感知分；同时报告理论 FLOPs 与实测延迟 | MSE、MAE（全部测试窗口计分），3 个种子的均值 ± 标准差 |
| 普遍性要求 | 至少两个 benchmark 上现象一致 | 至少两个数据集上现象一致 |

共同项：

- **定位**：修士毕业论文，约 1 年。
- **算力**：实验室电脑单张 GPU，型号与显存待在实验室电脑上用 `nvidia-smi` 确认。
- **备份**：实验室电脑 D 盘。
- **预算上限**：单个 idea 试验阶段 30 次运行或 20 GPU 小时；baseline 复现一周（见研究流程“实验执行规范”）。

交接细节见 [实验室会话交接](实验室会话交接.md)。
