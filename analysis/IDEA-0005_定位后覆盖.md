## 要解决的问题

- 路由把开放式题（VQAv2 的 other、number，GQA 的 query、choose 等）交给强对照 A：位置校正后的注意力、按 6 × 6 块轮流取。A 的选择几乎不随题目变化（F15、F28）。
- 开放式题上的损失来自被问区域里留的 token 太少（F45、F46）：答案物体的 token 被挤掉时损失最大；颜色题上，物体上留得越多越准。
- EXP-0024 的覆盖 16（对照）同一预算下比路由 +1.51 [+0.86, +2.14] / +0.98 [+0.28, +1.71]，不路由题上 +3.09 / +1.79（F50）：
  - 增益依赖框盖住话题物体：+4.46 对 +0.50；
  - 框离图像中心的远近几乎不影响增益；
  - 基线自己在框里留得少时增益更大。
- 运行记录显示，覆盖 16 在多数题上把 30 个保留 token 全放进了框里（VQAv2 67.7%、GQA 89.2%），框平均占网格的 39% / 43%。所以它实际上接近“只在题目定位的区域里、按基线自己的规则选 token”。

## 方法（不加模型前向，不改 token 预算）

1. **路由不变**（[IDEA-0003](IDEA-0003_按题目句式路由.md)）：yes/no 与 how many 题用题目查询（A′+B+V）。
2. **其余题（不路由）先定位**：
   - 题目查询 q 是题目各词输入 embedding 的加权均值，权重为 IDF × 可见性（IDEA-0002）；
   - 算 576 个图像 token 的输入 embedding 与 q 的余弦，取非填充区最高的 8 个，围出正方形框；
   - 框的边长 8～16 个 patch，下限是原图分辨率所占的边长，框限制在图像的内容带里（与 IDEA-0004 的定位相同，代码已提交）。
3. **再覆盖**：框内名额 = A 自己在框内的个数 + n（n = 16，上限 keep），按 A 的规则（除以位置先验的注意力，分块轮流）在框内取，其余名额按同一规则在框外补齐。
4. **K 的取法**：在第 2 层剪、留 30 个（层平均 64.1），或在第 1 层剪、留 47 个（63.5）。K = 1 是 FastV 的超参数，不是本模块的贡献；它在开发集上 +3.31 / +1.15（F51），所以作为预算杠杆一起测，并单独报告。
5. **代价**：与路由相同。覆盖 16 每题 0.174 秒，路由 0.174 秒（VQAv2 dev2）；峰值显存相同。

## 假设与机制（M18，AI）

- **假设**：
  - A 不看题目，在被问区域里留的 token 不够；
  - 输入层的题目查询就能大致定位被问区域：定位框盖住话题物体至少一半的占 88%；
  - 在框内用 A 自己的规则多留，补上证据；框外的少数 token 保留全局。
- **替代解释**：
  - ①增益只来自把名额集中到图像中部的一块，与题目无关。居中框的覆盖对照可以区分。
  - ②K = 1 与覆盖修的是同一批题（SQZ-EXP-0024 S6），合用时增益不一定相加。
  - ③开放式题里有一部分要看整体（场景、读字），集中到一块会受损。GQA 的 choose 类 −1.82 可能属于这一类（问两个物体）。

## 可检验的预测（推断，用于事后对照，不是判据）

- 定位框覆盖 − 居中框覆盖 > 0（两集平均），K = 2 与 K = 1 都是。
- K = 1 上覆盖 16 − K = 1 路由 > 0，但小于 K = 2 上的 +1.51 / +0.98（S6 的重叠）。
- 覆盖 8 介于路由与覆盖 16 之间。

  - 覆盖 16（K = 1）；

## 相近工作与新颖性

- IDEA-0004 的查新已经指出“覆盖单独看不新”：
  - **F³A**（arXiv 2605.16359）：免训练、不加 LLM 前向，先粗定位证据，再局部细化，同时保留覆盖、回收覆盖不足的区域，在固定预算内完成。模型是 Qwen3-VL、Qwen2.5-VL、InternVL3.5，没有 LLaVA-1.5。
  - **FSR**（arXiv 2602.05809）：把固定预算分成 focus、scan、refine，都在一次编码内选择或合并。
  - **CROP**（EMNLP 2025）：用微调的小模型预测区域，K = 2 时只留区域 token；同样大小的居中或随机区域会大幅下降。
  - **RoRA**（arXiv 2608.07088）、**ET-Prune**（arXiv 2608.01979）：按区域或证据分配预算，未读正文。
- 可以成立的贡献（推断）：
  - 不训练、不加任何前向，用输入层 embedding 的题目查询定位，与按题目句式的路由合成一条流程；
  - 在同一 LLM token 预算下，“把名额挪进定位区域”明显好于“用重新编码的裁剪换掉名额”（F49、F50），并有定位的对照证据；
  - 增益依赖框盖住被问物体，这一机制证据是在 FastV 一族上测得的。

## 风险

- **新颖性有限**：区域级的预算分配已有 F³A、FSR、CROP 等先例（见上一节）。论文的贡献只能写成“免训练、零额外计算的组合与机制证据”，不能写成新的范式。
- **只作用于不路由的题**：POPE、MME 的题目几乎全被路由，这两个 benchmark 上没有作用；增益只在开放式题。
- **定位失败**：物体很大、题目不点名物体、读字题；居中框对照可以看出有多少增益与定位无关。
- **开发集复用**：EXP-0024 的参照与覆盖 16 已看过；本轮只新增 4 种配置，确认用没用过的数据。
