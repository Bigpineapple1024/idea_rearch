## 本轮深挖的对象：选择算子

- **打分。** 取第 K−1 = 1 层上 prompt 最后一个 token 的 softmax 注意力行，在 32 个 head 上取平均，再截取图像 token 的部分（`fastv_llava.py` 第 85 行，`attn.mean(dim=1)[0, -1, start:start + n_cur]`）。
  - POPE 用 vicuna_v1 模板，prompt 以 “ASSISTANT:” 结尾，所以每道题的这个 query 都是同一个模板 token “:”。
  - 它和题目的关联只能来自第 0、1 层把题目信息混进这个位置。
- **去位置。** 分数除以纯灰图上的位置曲线（第 88 行，EXP-0008）。
- **覆盖。** 按 6×6 个块（每块 4×4 个 patch）轮流取（`_stratified_top`，第 42～54 行）。
- **保留与生效。** 保留 k = 30 个，从第 2 层起生效；第 0、1 层仍有全部 576 个图像 token。
- **图像预处理。** 先居中补成正方形，再切成 24×24 个 patch（`llava/mm_utils.py` 第 152～163 行 `expand2square`；模型 config 的 `image_aspect_ratio` 为 `pad`）。
  - POPE 的 500 张图里有 385 张横图、97 张竖图、18 张方图。
  - 4:3 的横图上下各有 3 行 patch 是纯填充。
- **对照：SparseVLM 的做法。**
  - 在输入嵌入层，按视觉与文本嵌入的点积选出作为“评分者”的文本 token（E-SV-C04）。
  - 在第 2、6、15 层，用评分者对视觉 token 的注意力打分，在 head 上取平均（E-SV-C07）。
  - 另外还有回收机制；它对 F19 那 15.5 分的贡献没有和评分者拆开。

## 新颖性（2026-10-24 检索，只到检索摘要级）

- **CDPruner**（NeurIPS 2025，arXiv 2506.10967）：在指令条件下计算 token 间的相似度，再用 DPP 选出既与指令相关、又互不重复的子集。**“题目相关 + 覆盖”这个组合已经有人做过。**
- **LearnPruner**（ICLR 2026，arXiv 2604.23950）：在 LLM 中间层用文本到视觉的注意力剪枝；指出视觉编码器的注意力有 attention sink，对前景的关注差。
- **SparseVLM**：用题目文本 token 作评分者（PAPER-0005）。
- **RePOPE**（arXiv 2504.15707）：重新标注了 POPE 的 500 张图，报告标注错误会改变模型排名；与 F27 一致。
- **填充区**：两次检索都没找到报告“FastV 在 LLaVA-1.5 上偏选填充区”的工作（检索未穷尽）。

结论：
- 候选 1 中“题目相关的打分 + 强制覆盖”的新颖性降为低，第 ⑦ 步的排序文档同步注明。成功可能性不变，因为已有方法证明这个方向在本设置下有效。
- 有可能和已有方法做出区别的，是本轮找到的两个算子级问题：
  - **小物体的命中**：与题目无关的选择只能按面积碰运气；即使是 SparseVLM-64，也漏掉了最小一档中 vanilla 答对的 34.7%。
  - **剂量**：抽中之后，物体上保留的 patch 太少，仍然认不出。

## 第 2 轮诊断（预先写定，GPU 空出后运行）

**D2：只记录，不改变选择（1 次运行，约 25 分钟）**

- 配置：全量 POPE，用强对照配置，与 EXP-0010-R05 相同。只多记录信息、不改计算，所以答案应与 R05 完全一致，同时作复现检查。
- 额外记录两项：
  - 每题的保留集合；
  - 第 1 层上所有文本 token 那几行对 576 个图像 token 的注意力（head 平均），以及这些 token 的 id。
- 离线计算：
  - 同图不同题的 Jaccard（各取 top-30），三种打分分别算：最后一个 token 那一行、题目 token 各行的均值、物体名 token 那几行。
  - 物体聚焦：被问物体 patch 上的注意力质量，除以物体的面积占比。
  - 模拟选择下的命中率（至少保留一个物体 patch）和物体上保留的 patch 数，按大小五档统计。模拟的选择方式包括全局 top-30 和 6×6 分块，再分别加上或不加去位置、排除填充区。
  - 在实际保留的集合下，答 yes 的比例随“物体上保留的 patch 数”（0、1、2～3、≥ 4）如何变化。
- 预测：
  - P1：题目行的同图不同题 Jaccard 比最后一个 token 行至少低 0.1。
  - P2：题目行在被问物体上的注意力质量高于物体的面积占比（比值 > 1），也高于最后一个 token 行。
  - P3：在最小两档的正样本上，“题目行 + 分块”的模拟命中率比强对照至少高 10 个百分点。
- 判读：
  - P1、P2 不成立：第 1 层的注意力由 key 决定，题目行也帮不上忙。
  - P3 不成立：第 1 层的题目注意力不足以找到小物体，候选 1 在 K = 2 下的上限有限。这时回到 2a，换层或换算子，例如在嵌入层算相似度（SparseVLM 选评分者的方式）。

**D3：块内改用题目行打分（1～2 次运行）**

- 前提：D2 的 P3 成立。
- 做法：其余与强对照完全相同，只把块内排序换成题目行的分数，跑 POPE 和 MME。
- 判据：POPE 比强对照高，配对区间在 0 以上；MME-P 不低于强对照，降幅不超出区间。

**预算**：候选 1 的运行从 0 开始计数（D2 1 次，D3 2 次），上限 30 次运行或 20 个 GPU 小时。

**评测注意（F27）**：后续的主要结果同时报告“只用 COCO 中有同名实例的正样本”的召回。RePOPE 的修订标注需要先得到下载许可。

## 交给第 ⑨ 步的底层问题（暂定）

**问题**：在固定的小预算下，从 576 个单元中选一个子集，要让被问的目标（只占 1～10 个单元）至少有几个单元被保留下来。与问题无关的显著性打分做不到这一点，只能按面积碰运气。

**可以去检索的机制方向**：
- 查询条件下的子集选择与覆盖：信息检索中的 MMR；DPP 的“质量 × 多样性”分解（CDPruner 已经用了）。
- 主动视觉搜索与注视点分配。
- 按目标先验布置传感器。
- 免训练地“看小细节”：先用注意力定位，再放大该区域。

## 停止、回退或推进的依据

- D2 的 P3 成立 → 做 D3。
- D3 成立 → 进入第 ⑨ 步，用上面的底层问题去检索领域 B。
- P3 不成立 → 回到 2a。

当前可靠的认识：
- 剩下的漏答集中在小物体上。
- 被问物体一个 patch 都没保留时，模型几乎总答 no。
- 与题目无关的选择保住小物体的概率，接近按面积碰运气的水平。
- FastV 的位置偏差把约三分之一的名额花在了横图下方的填充区。

仍属推断的部分：
- 换成题目行就能提高小物体的命中。
- 物体 patch 太少，是大物体也被漏掉的原因。

AI 的连贯解释不能证明根因，未经验证的因果边保持假设标记。
