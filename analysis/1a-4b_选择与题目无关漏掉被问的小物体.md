## 本轮深挖的对象：选择算子

- **打分。** 取第 K−1 = 1 层上 prompt 最后一个 token 的 softmax 注意力行，在 32 个 head 上取平均，再截取图像 token 的部分（`fastv_llava.py` 第 85 行（2026-10-29 完整阅读补注：这是 code/token-pruning 的 c3fc912（2026-10-24）版本的行号；7ba3657 中这条语句在第 293 行，按语句查找），`attn.mean(dim=1)[0, -1, start:start + n_cur]`）。
  - POPE 用 vicuna_v1 模板，prompt 以 “ASSISTANT:” 结尾，所以每道题的这个 query 都是同一个模板 token “:”。
  - 它和题目的关联只能来自第 0、1 层把题目信息混进这个位置。
- **去位置。** 分数除以纯灰图上的位置曲线（第 88 行，EXP-0008）（2026-10-29 完整阅读补注：c3fc912 版本的行号；7ba3657 中除以位置先验在第 298 行）。
- **覆盖。** 按 6×6 个块（每块 4×4 个 patch）轮流取（`_stratified_top`，第 42～54 行）（2026-10-29 完整阅读补注：c3fc912 版本的行号；7ba3657 中从第 84 行到第 95 行，多了 taken 参数）。
- **保留与生效。** 保留 k = 30 个，从第 2 层起生效；第 0、1 层仍有全部 576 个图像 token。
- **图像预处理。** 先居中补成正方形，再切成 24×24 个 patch（`llava/mm_utils.py` 第 152～163 行 `expand2square`；模型 config 的 `image_aspect_ratio` 为 `pad`）。
  - POPE 的 500 张图里有 385 张横图、97 张竖图、18 张方图。
  - 4:3 的横图上下各有 3 行 patch 是纯填充。
- **对照：SparseVLM 的做法。**
  - 在输入嵌入层，按视觉与文本嵌入的点积选出作为“评分者”的文本 token（E-SV-C04）。
  - 在第 2、6、15 层，用评分者对视觉 token 的注意力打分，在 head 上取平均（E-SV-C07）。
  - 另外还有回收机制；它对 F19 那 15.5 分的贡献没有和评分者拆开。

## 新颖性（2026-10-24 检索，只到检索摘要级）

- **CDPruner**（NeurIPS 2025，arXiv 2506.10967）：在指令条件下计算 token 间的相似度，再用 DPP 选出既与指令相关、又互不重复的子集。**“题目相关 + 覆盖”这个组合已经有人做过。**
- **LearnPruner**（ICLR 2026，arXiv 2604.23950）：在 LLM 中间层用文本到视觉的注意力剪枝；指出视觉编码器的注意力有 attention sink，对前景的关注差。
- **SparseVLM**：用题目文本 token 作评分者（PAPER-0005）。
- **RePOPE**（arXiv 2504.15707）：重新标注了 POPE 的 500 张图，报告标注错误会改变模型排名；与 F27 一致。
- **填充区**：两次检索都没找到报告“FastV 在 LLaVA-1.5 上偏选填充区”的工作（检索未穷尽）。

结论：
- 候选 1 中“题目相关的打分 + 强制覆盖”的新颖性降为低，第 ⑦ 步的排序文档同步注明。成功可能性不变，因为已有方法证明这个方向在本设置下有效。
- 有可能和已有方法做出区别的，是本轮找到的两个算子级问题：
  - **小物体的命中**：与题目无关的选择只能按面积碰运气；即使是 SparseVLM-64，也漏掉了最小一档中 vanilla 答对的 34.7%。
  - **剂量**：抽中之后，物体上保留的 patch 太少，仍然认不出。

## 交给第 ⑨ 步的底层问题（暂定）

**问题**：在固定的小预算下，从 576 个单元中选一个子集，要让被问的目标（只占 1～10 个单元）至少有几个单元被保留下来。与问题无关的显著性打分做不到这一点，只能按面积碰运气。

**可以去检索的机制方向**：
- 查询条件下的子集选择与覆盖：信息检索中的 MMR；DPP 的“质量 × 多样性”分解（CDPruner 已经用了）。
- 主动视觉搜索与注视点分配。
- 按目标先验布置传感器。
- 免训练地“看小细节”：先用注意力定位，再放大该区域。

**第 2 轮后的补充（2026-10-24）**：题目相关的打分已经解决了“保不住”的大部分。新的底层问题是：**查询目标可能不存在时，按查询相似度选出的子集会制造假证据**。可检索的机制方向：
- 开放集识别与带拒识的检索：相似度要与“背景”或“无关查询”的相似度对比，而不是只取最大；
- 对比式打分，例如减去对通用提示的相似度；
- 检测中的难负样本与校准。

## 第 3 轮的结果（2026-10-24，EXP-0013，[SQZ-EXP-0013](实验报告/EXP-0013_squeeze.md)）

开发集 coco_dev3 在 coco_dev 上补了 POPE 式的 popular、adversarial 负样本，复现了 F30（变体误报 38 / 68 / 136，vanilla 30 / 47 / 95）。三个假设与一个修正问题的结果：

| 问题 | 结果 | 对 2b 因果链的影响 |
| --- | --- | --- |
| H2 阈值偏移 | 不成立：变体的 margin AUC 比 vanilla 低 0.014～0.020 | 选择本身丢了区分信息 |
| H1 浓度 | 成立：按物体名选的越少误报越少；但召回掉得更多，F1 降 1.4～2.1 | “像”的 token 太集中是原因之一，但静态切分不划算 |
| H3 相似物体 | 部分支持：误报题保留的 token 更多落在其他物体上；与其他类名比的对比打分误报略少、召回略高，F1 +0.49（区间跨 0） | 相似物体有贡献，单靠对比不够 |
| 修正 | 最好的是校准（+0.97 [−0.01, +2.04]），未过门槛；不跑 POPE | — |

**新的因果边（第 3 轮补入）**：按物体名相似度选 30 个 → 场景中实际存在的内容大多被删掉，留下相似物体 → 被问物体不存在时，模型缺少判断“没有”的依据（负样本的 margin 抬高 0.9～1.5（审计修正，DEC-0030；原写 1.2～1.5），正样本只降 0.35）→ 误报增加、区分力下降。状态：部分支持（margin、Q3、切分实验为 DE；“依赖看到场景内容”为 AI）。

**交给第 ⑨ 步的底层问题（第 3 轮后改写）**：在固定的小预算下选择证据，而被问的假设可能是错的。只选“支持假设”的证据（最像被问物体的 token），会同时丢掉否定假设所需的证据；两种证据的比例若固定，就只能在召回与误报之间交换。需要的是**按“能区分假设真假”来选证据**的机制，或按题自适应地分配两种证据。可检索的机制方向：
- 主动假设检验 / 序贯实验设计：选最能区分两个假设的观测；
- 搜索论：目标可能不存在时，有限搜索力怎样分配；
- 开放集识别、匹配中的比值检验：与其他候选比（F33 是初步证据）；
- 检索增强生成中对“相似但无关”文档的处理（S-22）、相似度图中减去类别共有成分（S-23）。

- D2 的 P3 成立 → 做 D3。
- D3 成立 → 进入第 ⑨ 步，用上面的底层问题去检索领域 B。

当前可靠的认识：
- 剩下的漏答集中在小物体上。
- 与题目无关的选择下，被问物体一个 patch 都没保留时，模型几乎总答 no。
- 与题目无关的选择保住小物体的概率，接近按面积碰运气的水平。
- FastV 的位置偏差把约三分之一的名额花在了横图下方的填充区。
- （第 2 轮）FastV 打分层（第 1 层）的注意力不看题目，换成题目行也没用；输入层的物体名 embedding 余弦能保住小物体，POPE F1 +19。
- （第 2 轮）题目相关的选择让误报增加到超过不剪枝的模型。
- （第 3 轮）误报不只是阈值偏移：变体的区分力（margin AUC）比 vanilla 低；负样本失去“没有”的把握。名额切分、对比打分、校准都没有显著提高开发集 F1。
- （第 3 轮）POPE 式 F1 下，所有模型的最优阈值都偏向多答 yes，只压误报提不高 F1（F32）。

仍属推断的部分：
- 物体 patch 太少，是大物体也被漏掉的原因。
- 误报来自“留下了最像被问物体的区域”，并且删掉了场景中实际存在的内容（第 3 轮支持前者的一部分；覆盖变差已排除：两者都是 30 个 token 分在 30 个块里）。
- 一部分“只有变体误报”的题是 COCO 漏标的真实物体。
- 输入层余弦有效，是因为投影把图像 token 放到了与词 embedding 可比的空间。

已被第 2 轮否定的推断：换成第 1 层的题目行，就能提高小物体的命中。

AI 的连贯解释不能证明根因，未经验证的因果边保持假设标记。
